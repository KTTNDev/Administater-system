## ความสามารถ

- แบบหนังสือ 13 แบบ รวมภายนอก ภายใน คำสั่ง ระเบียบ ประกาศ หนังสือรับรอง และรายงานการประชุม
- ตัวหนา ตาราง เอกสารแนบท้ายหลายฉบับ ภาพแนวนอน/ตั้ง ข้อความลอย และภาพ QR ที่จัดตำแหน่งเองได้
- ภาพลายเซ็น PNG/JPG คลิกวาง ลากย้าย ปรับขนาด และบันทึกไว้กับร่าง ([วิธีใช้](docs/SIGNATURE-IMAGES.md))
- ส่งออก Word (.docx) ทุกแบบหนังสือ รวมบันทึกโอนงบ ข้อความและตารางแก้ไขได้ พร้อมฝังฟอนต์ไทย
- ตราสำเนาคู่ฉบับและตราร่างแยกจากต้นฉบับ พร้อมส่งออก PDF และรวมไฟล์แนบ
- เก็บไฟล์สแกนฉบับลงนามกับร่าง แสดงสถานะไฟล์ลงนาม ค้นหา ถังขยะ และกู้คืน
- ตรวจเลขซ้ำและจองเลขทะเบียนในฐานข้อมูลของเครื่องนี้ เก็บประวัติเลขแม้ย้ายร่างเข้าถังขยะ
- สำเนากู้คืนระหว่างกรอก สำรองตามรอบ และตรวจชุดสำรองก่อนนำกลับมาใช้
- งานธุรการ โอนงบประมาณ ปฏิทิน ห้องประชุม คลังระเบียบ และรายงานจากข้อมูลจริง
- อัปเดตผ่าน Update-Sarabun.cmd พร้อมสำรองและย้อนรุ่นด้วย Rollback-Sarabun.cmd

## พัฒนาและทดสอบ

- [คู่มือนักพัฒนา 1.4.1: PDF และแบบฝึก TypeScript](docs/handbooks/README.md)

ใช้ Node.js 22.13 ขึ้นไป ติดตั้งด้วย `npm ci` แล้วคัดลอก `.env.example` เป็น `.env.local` และตั้ง SESSION_SECRET ของตัวเอง หยุดโปรแกรม desktop ก่อนรัน dev เพื่อไม่ชนพอร์ต 3000

```powershell
npm run dev
npm test
npm run typecheck
npm run desktop:build
npm run test:release
```

`test:release` ใช้ desktop build ล่าสุด เปิดเซิร์ฟเวอร์ทดสอบบนพอร์ต 3100 และสร้างฐานข้อมูลใหม่ใต้ `output/v1-tests` ทุกครั้ง ไม่อ่านข้อมูลหรือ OAuth ของผู้ใช้ ผลลัพธ์และไฟล์ทดสอบไม่ส่งเข้า Git

เมื่อ clone จาก GitHub ให้คัดลอกเฉพาะ `data/budget-references` และ `data/template-references` จากชุด Clean เพื่อรันทดสอบคู่มือและเอกสารอ้างอิงครบชุด ไฟล์ PDF อ้างอิงไม่ได้เก็บใน Git และไม่ต้องคัดลอกฐานข้อมูลส่วนตัว

ตัวโปรแกรมเต็มรวม Node runtime ไว้แล้ว ต้องมี Edge หรือ Chrome สำหรับหน้าต่างโปรแกรมและสร้าง PDF การแก้ source ต้อง build ใหม่ก่อนทดสอบ desktop

## ข้อมูลและขอบเขต

SQLite เก็บร่าง เอกสารแนบ รูปภาพ ไฟล์ลงนาม และทะเบียนเลข ใช้ transaction และตรวจ version เพื่อป้องกันเขียนทับร่างที่แก้จากอีกหน้าต่าง สำเนากู้คืนเป็นข้อมูลแยกจากทะเบียน ยังต้องกดบันทึกร่าง

การสำรองอัตโนมัติทำงานเมื่อเปิดเซิร์ฟเวอร์ ชุดสำรองทั่วไปไม่รวม OAuth ส่วนชุด Personal และชุดสำรองก่อนอัปเดตรวมการตั้งค่าส่วนตัวด้วย ห้ามเผยแพร่ `.env.local`, `data`, `output`, `.desktop` หรือชุด Personal

การเลือกสถานะตรวจทานและอัปโหลดสแกนไม่ใช่การอนุมัติออนไลน์หรือลายเซ็นอิเล็กทรอนิกส์ การออกหนังสือต้องตรวจเนื้อหา อำนาจผู้ลงนาม และแบบของหน่วยงาน ระบบจองเลขเฉพาะในเครื่อง ไม่รวมทะเบียนของระบบอื่น ไม่รองรับการแก้พร้อมกันหลายเครื่องหรือ Shared Drive ใน V1

ดูผลการทดสอบจริงและรายการตรวจรับบนเครื่องอื่นในเช็กลิสต์ ไม่ถือว่าการสร้าง PDF สำเร็จเป็นการรับรองความถูกต้องตามระเบียบทุกกรณี
