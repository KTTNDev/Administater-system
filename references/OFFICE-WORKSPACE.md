# ศูนย์งานธุรการเทศบาล

เปิด http://127.0.0.1:3000/?view=office หรือเมนู งานธุรการเทศบาล

## ฟังก์ชันที่ใช้งานได้

| หมวด | การใช้งาน |
| --- | --- |
| ทะเบียนหนังสือรับ | บันทึกเลขทะเบียน วันที่รับ ต้นทาง ผู้รับผิดชอบ และเชื่อมร่างหนังสือ |
| ทะเบียนหนังสือส่ง | บันทึกเลขทะเบียน วันที่ส่ง ปลายทาง และสถานะติดตาม |
| งานและกำหนดส่ง | มอบหมายงาน ระบุวันติดตามและความสำคัญ ติดตามงานเกินกำหนด |
| การประชุม | บันทึกวัน สถานที่ เวลา วาระ ผู้เข้าร่วม มติ และผลติดตามในรายละเอียด |
| ทำเนียบหน่วยงาน | เก็บหน่วยงาน ผู้ติดต่อ โทรศัพท์ อีเมล และลิงก์ |
| วัสดุสำนักงาน | บันทึกยอดคงเหลือ หน่วยนับ และจุดเติม แสดงรายการที่ถึงจุดเติม |
| ดัชนีแฟ้มเอกสาร | บันทึกรหัสแฟ้ม ตู้/ชั้น วันทบทวน และลิงก์เอกสาร |

ทุกหมวดสร้าง แก้ไข ลบ ค้นหา กรองสถานะ และส่งออก CSV ตามผลค้นหาได้ ข้อมูลบันทึกใน SQLite พร้อมประวัติการแก้ไขใน audit และป้องกันการเขียนทับฉบับเก่าจากหลายหน้าต่าง

งานประจำ 5 แบบเปิดฟอร์มตั้งต้นได้ โดยยังไม่สร้างระเบียนจนกดบันทึก เลขทะเบียนผู้ใช้กรอกตามทะเบียนหน่วยงาน ระบบยังไม่ออกเลขราชการอัตโนมัติ การเตือนกำหนดส่งแสดงในหน้าเว็บเมื่อเปิดใช้งาน ยังไม่มีการส่งอีเมลหรือแจ้งเตือนเบื้องหลัง

วัสดุเป็นยอดคงเหลือที่ผู้ใช้ปรับเอง ยังไม่ใช่บัญชีรับ–จ่ายพัสดุหรือระบบจัดซื้อจัดจ้าง และดัชนีแฟ้มยังไม่อนุมัติการทำลายเอกสาร หมวดการประชุมใช้เก็บวาระและมติ ส่วนการจัดสรรห้องและตรวจเวลาซ้อนใช้เมนู **จองห้องประชุม** แยกต่างหาก ดู [คู่มือการจอง](MEETING-BOOKINGS.md)

ลิงก์ Drive เปิดไฟล์ที่ผู้ใช้ระบุได้ แต่ระเบียนงานธุรการชุดนี้เก็บในเครื่อง ยังไม่ได้ซิงก์ฐานข้อมูลงานขึ้น Drive อัตโนมัติ

## แนวทางพัฒนาระยะต่อไป (ยังไม่ได้พัฒนา)

1. ผู้ใช้หลายคน สิทธิ์รายหน่วยงาน และมอบหมายงานพร้อมประวัติรายบุคคล
2. เลขทะเบียนตามสมุดและปี พร้อมรายการยกเลิกเลขและป้องกันเลขซ้ำ
3. เชื่อมการจองห้องประชุมกับปฏิทินภายนอกและขั้นตอนอนุมัติ (การจองและตรวจเวลาซ้อนภายในระบบมีแล้ว)
4. แจ้งเตือนครบกำหนดตามช่องทางที่หน่วยงานอนุญาต
5. บัญชีวัสดุรับ–จ่ายและประวัติการเคลื่อนไหว
6. สำรอง/กู้คืนข้อมูลพร้อมตรวจสอบไฟล์ และซิงก์งานธุรการขึ้น Drive
7. อ่าน PDF/OCR และแนะนำข้อมูลหนังสือรับให้เจ้าหน้าที่ตรวจยืนยัน
8. ขั้นตอนเสนอและอนุมัติ พร้อมตรวจอำนาจและเก็บหลักฐานการลงนาม

รายละเอียดที่เกี่ยวกับระเบียบ อายุเก็บเอกสาร และอำนาจอนุมัติต้องตรวจจากแหล่งทางการก่อนพัฒนาเป็นเงื่อนไขบังคับของระบบ
