# พื้นที่จัดเก็บ รายงาน และการซิงก์

## ใช้งาน
- ตั้งค่า: http://127.0.0.1:3000/?view=settings
- รายงานรวม: http://127.0.0.1:3000/?view=reports
- คลังระเบียบ: http://127.0.0.1:3000/?view=laws

กำหนดโฟลเดอร์สำเนาและส่งออกได้ในตั้งค่า ค่าเริ่มต้น `D:\sarabun\output\storage` ฐานข้อมูลที่ใช้งานอยู่คือ `D:\sarabun\data\sarabun.sqlite` การเปลี่ยนโฟลเดอร์สำเนาไม่ย้ายฐานข้อมูลหรือไฟล์เดิม กดคัดลอกพาธแล้ววางใน File Explorer ได้

ปุ่มส่งออกข้อมูลทั้งหมดสร้าง JSON แต่ละหมวด พร้อม PDF ในคลังกฎหมายและ manifest ที่มีจำนวนระเบียนและ SHA-256 ไม่ส่งออกตาราง settings ซึ่งมีข้อมูลรับรองและ OAuth token ปุ่มเก็บ PDF หนังสือทั้งหมดสร้าง PDF ทีละฉบับพร้อมผลสำเร็จ/ผิดพลาด ส่งออกไม่ใช่การกู้คืนอัตโนมัติ ต้องเก็บชุดสำรองทั้งโฟลเดอร์

รายงานแสดงหนังสือ งานธุรการ ห้องประชุม การจอง ปฏิทิน คลัง และกิจกรรม 1,000 รายการล่าสุด กรองตามเดือนและส่งออก CSV ได้ ไม่ใช่สถิติรายผู้ใช้หรือจำนวนการเปิดหน้าเว็บ

## การเชื่อม Drive ที่ยังต้องดำเนินการ

การอัปโหลดผ่าน Google Drive connector ของแชททำงานแล้ว แต่เว็บไซต์เป็นแอปแยก ต้องมี `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `SESSION_SECRET` และ `APP_URL` จึงกดเชื่อมบัญชี Google ในหน้า settings ได้ ไม่สามารถยืมโทเคนของ connector มาใช้ในเว็บไซต์ได้

OAuth Client เป็นชนิด Web application และ callback ของระบบอยู่ที่ `/api/google/callback` บน APP_URL ต้องเปิด Drive API และตั้ง redirect URI ให้ตรงกัน ก่อนทดสอบโฟลเดอร์จริง ระบบขอ scope `drive.file` เท่านั้น หากโฟลเดอร์เดิมไม่ได้รับอนุญาตแก่แอป จะต้องให้บัญชีและแอปเข้าถึงโฟลเดอร์นั้นตามขั้นตอน Google ก่อน ไม่ขยายสิทธิ์เป็นทั้ง Drive อัตโนมัติ

โฟลเดอร์หลักที่ผู้ใช้ให้ไว้: https://drive.google.com/drive/folders/1RoVDuJDLfLjsTNwzbV9xYkMeV4oWkCQM
ตรวจพบสิทธิ์ anyone/reader วันที่ 14 ก.ย. 2569 จึงอัปโหลดเฉพาะเอกสารราชการสาธารณะที่ค้นได้ ยังไม่อัปโหลดข้อมูลระบบทั้งหมดลงโฟลเดอร์สาธารณะระหว่างรอผู้ใช้เลือกโฟลเดอร์สำรองส่วนตัวหรือเปลี่ยนการแชร์

ซิงก์รวมตรวจโฟลเดอร์สำรองก่อนเริ่ม ส่ง PDF หนังสือที่ตรวจทานแล้วและไม่ใช่หนังสือลับ ส่ง PDF คลังที่ยังไม่มีลิงก์ Drive และชุดสำรอง JSON/PDF แสดงผลแยกรายการ ปุ่มยังปิดเมื่อเว็บไซต์ไม่ได้เชื่อมบัญชี ไม่รายงานผลจาก connector เป็นการเชื่อมต่อของแอป
