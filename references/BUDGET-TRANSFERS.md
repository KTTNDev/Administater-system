# งานโอนงบประมาณ

เปิด `/?view=budget` หรือเมนู **โอนงบประมาณ** แล้วเพิ่มคำขอ หรือกด **ลองแพตเทิร์นจากไฟล์ตัวอย่าง**

## ต้นแบบ

วิเคราะห์เอกสารที่ผู้ใช้ให้: `E:/My Drive/เอกสารราชการ/โอนงบที่ไว้เป็นตัวอย่าง.pdf` จำนวน 7 หน้า วันที่ตรวจ 15 กันยายน 2569 ต้นฉบับเก็บไว้โดยไม่แก้ไข

ใช้โครงสร้างบันทึกข้อความ: เรื่องเดิม → ข้อเท็จจริง → โอนลด → โอนเพิ่ม/ตั้งจ่ายใหม่ → ข้อระเบียบ → ข้อเสนอแนะ → ผู้เสนอ → ความเห็น 5 ลำดับ โดยจำนวนหน้าปรับตามเนื้อหา ไม่บังคับเท่าต้นฉบับ

ตัวอย่างประกอบมีโอนลด 152,460 บาท จากคงเหลือ 281,000 บาท เหลือ 128,540 บาท และโอนเพิ่ม 6 รายการรวมเท่ากัน ได้แก่ Router 21,300 บาท, ตู้ติดผนัง 15,600 บาท, Switch 40,200 บาท, อุปกรณ์แปลงสัญญาณ 4,500 บาท, IP-PBX 32,100 บาท, IP Phone 38,760 บาท

ข้อมูลที่เติมให้นี้เป็นตัวอย่างสาธิต ใช้ชื่อรายการและจำนวนเงินเพื่อแสดงรูปแบบ ไม่คัดลอกชื่อผู้ลงนามหรือลายเซ็น และไม่ถือเป็นข้อกำหนดคุณลักษณะจัดซื้อ ผู้ใช้ต้องเติมคุณลักษณะ แหล่งอ้างอิง ยอดที่โอนได้จริงและรายละเอียดหน่วยงานก่อนใช้

ฐานอ้างอิง: ระเบียบกระทรวงมหาดไทยว่าด้วยวิธีการงบประมาณขององค์กรปกครองส่วนท้องถิ่น พ.ศ. 2563 หมวด 4 ข้อ 26 และ 27 จากเอกสารเผยแพร่ของหน่วยงานรัฐ:
https://www.khaochakan.go.th/_files/data/data_HmgqDBgp.pdf

ข้อ 26 เป็นอำนาจผู้บริหารท้องถิ่น ส่วนข้อ 27 ครอบคลุมการโอนงบลงทุนที่ทำให้ลักษณะ ปริมาณ คุณภาพเปลี่ยน หรือโอนไปตั้งจ่ายเป็นรายการใหม่ ซึ่งเป็นอำนาจสภาท้องถิ่น แบบฟอร์มให้ผู้ปฏิบัติงานตรวจและยืนยันข้อที่ใช้ ไม่ใช่เครื่องวินิจฉัยกฎหมายอัตโนมัติ

## การใช้งาน

1. กรอกปีงบประมาณ ข้อมูลหนังสือ เรื่องเดิม และเหตุผล
2. เพิ่มรายการโอนลดและโอนเพิ่มได้ด้านละ 20 รายการ ระบุหมวด/ประเภท/รายการ ยอดตั้งเดิม คงเหลือที่ใช้ได้ และยอดโอน
3. รายการตั้งจ่ายใหม่ให้ยอดเดิมเป็นศูนย์ ใส่จำนวนหน่วยและคุณลักษณะเป็นคนละช่อง
4. เลือกผู้มีอำนาจและตรวจข้อระเบียบ พร้อมปรับความเห็นผู้เกี่ยวข้อง
5. บันทึกคำขอได้แม้ยังไม่ครบ แต่สร้างบันทึกได้เมื่อยอดสมดุล ไม่โอนลดเกินคงเหลือ และข้อมูลหลักครบ
6. กดสร้าง/เปิดบันทึกข้อความเพื่อเข้าทะเบียนหนังสือเดิม จากนั้นแนบไฟล์ ตรวจทาน ส่งออก PDF หรือใช้ปุ่ม Drive ของระบบเดิมได้

## ข้อมูลและข้อจำกัด

- คิดเงินด้วยจำนวนเต็มหน่วยสตางค์ และตรวจฝั่งเซิร์ฟเวอร์ด้วย
- ตาราง SQLite `budget_transfers` เก็บคำขอแยกจาก `documents` มีเวอร์ชันป้องกันการแก้ทับและ audit
- สร้างเอกสารซ้ำจากเวอร์ชันเดิมจะเปิดฉบับเดิม แก้คำขอแล้วสร้างใหม่จะได้ร่างใหม่เพื่อไม่ทับการแก้ไขหนังสือเดิม
- ลบคำขอไม่ลบร่างหนังสือที่สร้างแล้ว ร่างเหล่านั้นจัดการในทะเบียนหนังสือ
- สำรองข้อมูลระบบรวมตารางคำขอโอนงบเมื่อมีการสร้างตารางแล้ว
- ข้อมูลรายละเอียดที่ปรับในหน้าร่างหนังสือไม่ย้อนกลับไปแก้คำขอโอนงบ หากแก้เนื้อหาเป็นข้อความอิสระ รูปแบบแยกช่องจะเปลี่ยนเป็นย่อหน้าของตัวแก้ไขเดิม
- ไม่ได้เชื่อมยอดบัญชี e-LAAS / New e-LAAS ไม่ได้ออกเลขหนังสือแทนทะเบียน ไม่บันทึกการอนุมัติหรือโอนเงินจริง
- การอัปโหลด Drive ต้องตั้งค่าและเชื่อม OAuth ของระบบให้สำเร็จก่อน โมดูลนี้ไม่ได้เปลี่ยนการตั้งค่าบัญชี

## จุดพัฒนา

- `src/lib/budget.ts`: แบบข้อมูล การตรวจยอด ตัวอย่าง
- `src/lib/budget-db.ts`: CRUD, optimistic concurrency, สร้างร่างแบบ transaction
- `src/lib/budget-document.ts`: แปลงคำขอเป็นบันทึกข้อความ
- `src/app/budget-actions.ts`: Server Actions ที่ตรวจสิทธิ์
- `src/components/budget-transfers.tsx`: ทะเบียน ฟอร์ม ตัวอย่าง A4
- `tests/budget.test.ts`, `tests/e2e/budget.spec.ts`: ตรวจยอด การบันทึก การสร้าง และการแบ่งหน้า


## ปรับรูปแบบและอ้างอิงรายรายการ (15 กันยายน 2569)

- เทียบตำแหน่งจาก PDF ต้นแบบ: ย่อหน้า/หัวข้อร่น 25.4 มม. จากขอบเนื้อหา ช่องค่ารายการและบรรทัดเงินเริ่ม 50.8 มม. รายละเอียดคุณลักษณะร่น 55 มม. ใช้บรรทัด 18.1 pt ใกล้ต้นฉบับ ปรับเฉพาะ layout `budget-reference`
- บรรทัดเงินแยกคอลัมน์ชื่อยอด / เป็นเงิน / จำนวนเงิน / บาท; ตั้งจ่ายใหม่ไม่แสดงยอดเดิมเป็นศูนย์ 3 บรรทัดเหมือนก่อน
- หน้าอ่านคู่ฟอร์มใช้ PDF.js เปิดหน้า PDF ที่เลือกได้ ไฟล์ต้นฉบับไม่ถูกแก้ไข
- เพิ่มดัชนีค้นในเอกสารคอมพิวเตอร์ 33 หน้า บัญชีครุภัณฑ์ 118 หน้า และฉบับ ICT พ.ค. 2569 จำนวน 9 หน้า
- ว 1095 เป็นสแกน 107 หน้า เปิดได้ครบ แต่ดัชนีค้นมีเฉพาะหัวข้อที่ตรวจด้วยภาพแล้ว ไม่ใช่ OCR ทั้งเล่ม
- รายการเลือกได้: ICT 70 รายการ (1–11 ใช้ฉบับ พ.ค. 2569; 12–70 ใช้ ธ.ค. 2568) และรายการสำนักงานที่คัดไว้ 11 รายการ; ครุภัณฑ์อื่นยังค้นตามข้อความในหน้า PDF และกรอกเลขรายการเองได้
- การแนะนำประเภท ICT เป็นแนวทางตามหน้า PDF 52 ของ ว 1095; รายการเช่า/ซอฟต์แวร์ไม่เติมงบลงทุนอัตโนมัติ
- กรณีตามบัญชี ให้ระบุฉบับ เลขรายการ หน้า และตรวจคุณลักษณะก่อนยืนยัน; กรณีนอกบัญชีให้ระบุเหตุผลและหลักฐานสืบราคา ไม่มีการฟันธงว่าไม่มีรายการจากผลค้นหาไม่พบ
- ชุดหนังสืออ้างอิง ว 1095 / ว 1989 / ว 7509 เป็นชุดตามต้นแบบ เลือกเฉพาะที่สัมพันธ์กับกรณีจริง โดย ว 7509 เป็นเรื่องแผนพัฒนาท้องถิ่น ไม่ใช่บัญชีราคา
- ข้อความอ้างอิงถูกบันทึกในคำขอและพิมพ์ใต้รายการนั้น ก่อนขึ้นรายการถัดไป ข้อ 26/27 ยังคงอยู่ท้ายบันทึก
- ไฟล์ทั้งสี่อยู่ `data/budget-references` และรวมในคำสั่งสำรองข้อมูลระบบ; สคริปต์สร้างดัชนีคือ `scripts/index-budget-references.py` (pypdf)
- ฉบับปรับปรุง ICT พ.ค. 2569 ตรวจจากกระทรวงดิจิทัลฯ https://mdes.go.th/service/29 ประกาศวันที่ 11 พฤษภาคม 2569 โดยหน้าปกระบุให้รายการ 12–70 ใช้ฉบับ ธ.ค. 2568 ต่อ
- ไฟล์ PDF เดิมที่ส่งออกแล้วไม่เปลี่ยนตามแม่แบบใหม่ ต้องแก้/บันทึกคำขอและสร้างร่างใหม่เพื่อใช้รูปแบบนี้
