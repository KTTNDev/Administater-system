# ผู้ช่วยเขียนในสารบรรณ

เปิดจากปุ่ม **ช่วยเขียนด้วย AI** ใต้ช่องเนื้อหา ใช้ได้ทั้งโหมดข้อความและโหมดจัดข้อความแบบ Word รวมถึงย่อหน้าแยกหัวข้อ เอกสารแนบท้าย หัวข้อ TOR ข้ออภิปราย มติ และคำพูดของผู้ประชุม

## Gemini API

1. สร้าง API key ที่ https://aistudio.google.com/apikey การมีบัญชี Gemini หรือสิทธิ์ Gemini Enterprise ผ่าน AIThaiPass ไม่ได้ทำให้มี API key และโควตา API โดยอัตโนมัติ
2. เลือก Gemini API ใส่ key และกด **โหลดรายชื่อโมเดล** ระบบจะแสดงโมเดลสร้างข้อความที่บัญชีเรียกได้ โดยไม่ผูกกับชื่อรุ่นที่อาจเลิกให้บริการ
3. เลือกงาน ระบุคำขอและข้อเท็จจริง หากต้องการอ้างข้อความเดิม ให้กด **ใช้ข้อความจากช่องนี้** แล้วตรวจแก้ข้อมูลประกอบก่อนส่ง ระบบไม่แนบทั้งเอกสารหรือฐานข้อมูลให้อัตโนมัติ
4. กด **ให้ Gemini ช่วยเขียน** ตรวจแก้คำตอบ แล้วเลือกเพิ่มต่อท้ายหรือแทนที่ การแทนที่ข้อความเดิมต้องกดยืนยันอีกครั้ง ย้อนกลับการนำเข้าครั้งล่าสุดได้ตราบใดที่ยังไม่ได้แก้ข้อความต่อ
5. ปิดหน้าต่างหรือกดล้าง key เมื่อเสร็จ key อยู่ในหน่วยความจำของหน้าต่างนี้เท่านั้น ไม่บันทึกลงฐานข้อมูล สำเนากู้คืน localStorage หรือชุดสำรอง การเรียก API ใช้โควตาและอาจมีค่าใช้จ่ายตามบัญชี Google

## TH-AI Passport

ณ วันที่ตรวจสอบ 4 พฤศจิกายน 2569 ข้อกำหนดข้อ 3.4 ของ https://aipass.go.th/term-and-cond-th จำกัดการเรียก API/API key/token โดยตรงนอกหน้าจอของบริการ เว้นแต่ได้รับอนุญาตเป็นลายลักษณ์อักษร ระบบจึงใช้ขั้นตอนที่ผู้ใช้ดำเนินการเอง:

1. เลือก **TH-AI Passport · คัดลอกคำสั่ง** และระบุคำขอ/ข้อมูลประกอบ
2. กด **คัดลอกคำสั่ง** เปิด https://aipass.go.th/ เข้าสู่ระบบด้วยตนเอง แล้ววางคำสั่ง
3. คัดลอกคำตอบกลับมาวางในช่องคำตอบ ตรวจแก้และกดนำเข้าเอกสาร

ขั้นตอนนี้ไม่ส่งคำขอไป AIThaiPass จากเซิร์ฟเวอร์ ไม่ดึง cookie/token ของบริการ และใช้ได้กับบริการแชทอื่นด้วยการคัดลอกคำสั่งเดียวกัน

## ข้อจำกัดและการดูแลต่อ

- AI ไม่ยืนยันความถูกต้องของกฎหมาย ชื่อ วันที่ ตัวเลข หรือการอนุมัติ เจ้าหน้าที่ต้องตรวจจากเอกสารจริงก่อนใช้ ตรวจข้อมูลลับและข้อมูลส่วนบุคคลก่อนส่งให้ผู้ให้บริการภายนอก
- คำตอบเป็นข้อความเท่านั้น ไม่แสดง HTML จาก AI และไม่แก้ preview/PDF/Word จนกว่าจะกดนำเข้า ใช้เครื่องมือจัดหน้าเดิมต่อได้
- ข้อมูลประกอบไม่เกิน 16,000 ตัวอักษร คำขอไม่เกิน 8,000 ตัวอักษร การนำเข้าแต่ละครั้งจำกัดข้อความรวมช่องนั้นที่ 10,000 ตัวอักษร (มติ 5,000) โดยไม่ตัดทิ้งเงียบ ๆ ถ้ายาวกว่านี้ให้ย่อหรือคัดลอกเฉพาะส่วนที่ต้องการ
- รอ API สูงสุด 60 วินาที ไม่ลองซ้ำอัตโนมัติ การหยุดรอไม่ได้รับรองว่าผู้ให้บริการยกเลิกการคิดโควตาแล้ว
- หากเนื้อหาเปลี่ยนระหว่างเตรียมคำขอและนำเข้า จะปิดการแทนที่ ป้องกันทับงานล่าสุด แต่ยังคัดลอก/เพิ่มต่อท้ายได้

เส้นทางโค้ด: `components/ai-writing-assistant.tsx` → `app/api/ai-writing/route.ts` → `lib/gemini-writing.ts` → Gemini API ใช้ `lib/ai-writing.ts` เป็นชนิดข้อมูล schema และตัวสร้างคำสั่งร่วมกัน ฝั่งเซิร์ฟเวอร์ตรวจ session, origin, ขนาดข้อมูล และชื่อโมเดล เรียกเฉพาะ hostname ของ Google โดยส่ง key ใน header และไม่ส่งข้อความ error ดิบจากผู้ให้บริการกลับผู้ใช้

เอกสารอ้างอิง: https://ai.google.dev/gemini-api/docs/api-key · https://ai.google.dev/api/models · https://ai.google.dev/api/generate-content

ทดสอบด้วยคำตอบจำลองเพื่อไม่ใช้โควตาหรือข้อมูลจริง การเชื่อมบัญชีจริงต้องให้ผู้ใช้ใส่ key ของตนในหน้าต่างผู้ช่วย ไม่ต้องส่ง key ในแชท
