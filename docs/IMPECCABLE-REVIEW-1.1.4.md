# ปรับ UX/UI ด้วย Impeccable — 1.1.4

17–18 ตุลาคม 2569

## แนวทางและขอบเขต

ใช้คำแนะนำจาก [Impeccable](https://impeccable.style/) และ [โครงการต้นทาง](https://github.com/pbakaus/impeccable) รุ่นเครื่องมือ 4.6.0 ในโหมด Operate ผ่าน critique, distill และ polish คงแนว Notion และความสะดวกในการทำหนังสือที่ผู้ใช้เลือกไว้ บริบทอยู่ใน PRODUCT.md และกติกาหน้าจออยู่ใน design.md

ใช้เป็นเครื่องมือระหว่างพัฒนา ไม่เพิ่ม Impeccable เป็น dependency ของโปรแกรม ไม่ส่งเอกสารหรือฐานข้อมูลผู้ใช้ไปให้บริการออกแบบ

## สิ่งที่พบและแก้แล้ว

| สิ่งที่พบ | การแก้ |
| --- | --- |
| งานล่าสุดและแบบหนังสือใช้การ์ดหน้าตาซ้ำกันจนแต่ละส่วนมีน้ำหนักเท่ากัน | งานล่าสุดเปลี่ยนเป็นแถวสั้น แยกพื้นที่เริ่มหนังสือใหม่ให้ชัด |
| หน้าเลือกแบบมีการ์ดเหมือนกันทั้ง 13 แบบ | ภายนอกและภายในมีภาพกระดาษขนาดใหญ่ ส่วนที่เหลือจัดตามหมวดเป็นรายการขนาดกะทัดรัด |
| หัวหน้าระบบ ไอคอน และรายการมีกรอบซ้อนหลายชั้น | ลดกล่องรอบไอคอนและกรอบรอบตาราง ใช้ช่องว่างกับเส้นแบ่งช่วยอ่าน |
| ทางลัดคำสั่งและประกาศถูกสไตล์เดิมซ่อนเมื่อหน้าต่างแคบ | แสดงทางลัดทั้ง 4 แบบและเพิ่มการทดสอบที่ 320–1,440 พิกเซล |
| สถานะเลือกและการโฟกัสไม่สม่ำเสมอ | ใช้สีจากชุดเดิมร่วมกันทั้งเมนู แท็บ ปุ่ม โฟกัสคีย์บอร์ด และข้อความที่เลือก |

การปรับ UI คงโครงสร้างเนื้อหาราชการและการเชื่อม Drive เดิม ส่วนการแนบลายเซ็นเพิ่มการจัดวางภาพลอยในตัวอย่าง PDF และ Word

## หลักฐานการตรวจ

- ตรวจหน้าแรกกับข้อมูลจริงในโปรแกรมบนเครื่อง และลองหน้าเลือกแบบ การกรองหมวด การเลื่อนลง และการเปิด/ปิดค้นหางาน
- ตรวจ source ด้วย Impeccable ก่อนและหลัง: พบคำเตือนเดิม 1 รายการเรื่อง Arial ใน globals.css และไม่มีคำเตือนใหม่ ไม่ใช้ผล detector เป็นคะแนนความสวยหรือคำรับรองว่าปราศจาก AI slop
- TypeScript และ desktop build ผ่าน
- Unit tests หลังเพิ่มลายเซ็น: 131 ผ่าน จาก 31 ไฟล์
- ผลทดสอบการใช้งานทั้งระบบรวมลายเซ็น: 168 ผ่าน (10.4 นาที)
- หลังแก้การวางลายเซ็นบนสำเนาคู่ฉบับ ตรวจกรณีลายเซ็นและภาพวางอิสระซ้ำ 5 รายการผ่าน และเพิ่มกรณีคลิกวางบนสำเนาอีก 1 รายการผ่าน
- ตรวจภาพหน้าแรก 320 / 375 / 1,440 พิกเซล หน้าแบบหนังสือ รายงาน และตั้งค่าแล้ว; สร้างชุดอัปเดตรวมลายเซ็นและตรวจ hash ครบ 2,229 ไฟล์แล้ว

ผลทดสอบใช้งานใช้ฐานข้อมูลแยกจากงานจริง ไฟล์ผลลัพธ์และภาพหน้าจออยู่ใต้ output และไม่นำขึ้น Git

## ขอบเขตของผลตรวจ

การตรวจครั้งนี้ประเมินหน้าตา การเข้าถึงปุ่ม และการทำงานเดิมหลังปรับ UI ไม่ใช่การทดสอบความพึงพอใจระยะยาวกับผู้ใช้หลายคน และไม่แทนการตรวจเนื้อหาหรืออำนาจลงนามของหนังสือราชการแต่ละฉบับ รายการตรวจรับบนเครื่องอื่นและ Microsoft Word ยังคงตาม SYSTEM-AUDIT-1.1.3.md

## ภาพลายเซ็นที่เพิ่มตามคำขอต่อเนื่อง

เพิ่มส่วนลายเซ็นในส่วนผู้ลงนาม ใช้ภาพ PNG/JPG คลิกวางบนหน้าตัวอย่าง ลากย้าย ลากมุมปรับขนาด หรือใช้แถบเลื่อนได้ บันทึกตำแหน่งไว้กับร่างและส่งออกเป็นภาพลอย รายละเอียดและขอบเขตอยู่ใน SIGNATURE-IMAGES.md

ตรวจ PDF ที่ส่งออกด้วยภาพจริงแล้ว: ลายเซ็นอยู่ตำแหน่งเดียวกับตัวอย่าง ไม่มีกรอบเลือกหรือจุดลากติดในงานพิมพ์ เปิดโปรแกรมรุ่นใหม่บนเครื่องนี้ได้ใน 2.7 วินาที (เป็นผลวัดครั้งนี้ ไม่ใช่การรับประกันเวลาบนทุกเครื่อง)
