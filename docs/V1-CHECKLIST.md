# เช็กลิสต์เวอร์ชัน 1.0.0

ผลตรวจใหม่วันที่ 13 ตุลาคม 2569: [ตรวจระบบรุ่น 1.1.3](SYSTEM-AUDIT-1.1.3.md)

รุ่นเพิ่มเติม 1.1.0 เพิ่มส่งออก Word ทุกแบบหนังสือ ดู [ความสามารถและผลตรวจ Word](WORD-EXPORT.md) รายการด้านล่างเก็บผลตรวจฐานรุ่น 1.0.0 เดิม

ตรวจล่าสุด 11 ตุลาคม 2569 — ขอบเขตผู้ใช้คนเดียวบน Windows x64

## งานพัฒนาและทดสอบที่เสร็จแล้ว

- [x] **1. ชุดทดสอบและกระบวนงาน** — Unit 107 ข้อ / 28 ไฟล์ผ่าน; E2E 66 กรณีผ่านทั้งหมดบน desktop build ด้วยฐานข้อมูลจำลองใหม่ เปิดฟอร์มครบ 13 แบบและเมนูหลักครบ 10 หน้า
- [x] **2. รูปแบบเอกสาร** — ตรวจการต่อข้อความ ตาราง 85 แถว หัวตารางซ้ำ ลายเซ็นอยู่กลุ่มเดียว ตราสำเนา/ตราร่าง และเอกสารแนบท้าย ทดสอบภาพแนวนอน/แนวตั้ง/ผสม และ PDF แนบหลายขนาด ตรวจภาพ PDF ภายใน–ภายนอกรวม 32 หน้า ขนาด A4
- [x] **3. การกู้คืนข้อมูล** — สำเนาระหว่างกรอกกลับมาได้หลัง reload; ถังขยะกู้คืนเอกสารพร้อมไฟล์ลงนาม; สำรองตามรอบ/สำรองทันที; นำชุดสำรองกลับมาใช้พร้อมสร้างสำรองก่อนแทนข้อมูล ผ่านฐานจำลอง
- [x] **4. อัปเดตและย้อนรุ่น** — Update-Sarabun.cmd ตรวจ checksum สำรองฐานข้อมูลและการตั้งค่า เปลี่ยนรุ่นและตรวจเปิด; ล้มเหลวจะกู้กลับ ย้อนภายหลังได้ด้วย Rollback-Sarabun.cmd และมีชุดเก็บงานหลังอัปเดต ทดสอบ unit 5 กรณีและทดลองกับโปรแกรมจริงในโฟลเดอร์จำลองแล้ว
- [x] **5. ชุดโปรแกรม** — แยก Clean / Personal / Update ตรวจ Clean ไม่มีฐานข้อมูลหรือ OAuth; เปิดได้เมื่อไม่มี Node ใน PATH; เปิดซ้ำไม่สร้างเซิร์ฟเวอร์ใหม่; ย้ายโฟลเดอร์แล้วเปิดและสร้าง PDF ได้
- [x] **6. UX ระหว่างทำงาน** — ทดสอบข้อความไม่หายเมื่อบันทึกผิดพลาด ลองใหม่ได้ ปุ่มบันทึกปิดระหว่างส่ง เตือนเมื่อออกโดยไม่บันทึก; แก้ข้อความลบกฎหมายที่ถูกอ้างอิงให้แสดงภาษาไทยแทนรหัส React ใน production
- [x] **7. รุ่นและคู่มือ** — package 1.0.0 แสดงเลขรุ่นในตั้งค่า มี CHANGELOG คู่มือเริ่มใช้/ย้ายเครื่อง/อัปเดต/ย้อนรุ่น และวิธีรันชุดทดสอบแยกข้อมูลจริง

## หลักฐานและวิธีทดสอบซ้ำ

- `npm test` — 107 ผ่าน
- `npm run typecheck` และ `npm run desktop:build` — ผ่าน
- `npm run test:release -- --reporter=line` — 66 ผ่าน ไม่มีกรณีข้าม
- `scripts/verify-portable-release.mjs <Clean-folder> <Update-folder>` — เปิด อัปเดต ย้อนรุ่น และย้ายโฟลเดอร์ผ่านบนเครื่องนี้ (สคริปต์หยุดแล้วเปิดโปรแกรมหลักกลับเมื่อจบ)
- ผลละเอียดบนเครื่องผู้พัฒนา: `output/v1-unit-final.log`, `output/v1-acceptance.log`, `output/v1-portable-check.json`, `output/print-check/` ไม่ส่งไฟล์ข้อมูลส่วนตัวเข้า Git

## การตรวจรับที่ต้องใช้อุปกรณ์จริง

- [ ] ทดลองบน Windows อีกเครื่องที่มี Edge/Chrome แต่ไม่มี Node.js — ยังไม่ได้เข้าถึงคอมพิวเตอร์อีกเครื่อง การย้ายโฟลเดอร์บนเครื่องเดียวไม่ใช่ผลทดสอบข้อนี้
- [ ] พิมพ์จากเครื่องพิมพ์จริงด้วย A4 / 100% แล้ววัดระยะและตรวจตัวอย่างของหน่วยงาน — รอบนี้ตรวจ PDF และภาพเรนเดอร์ ยังไม่ได้ใช้เครื่องพิมพ์จริง

งานพัฒนา V1 และการทดสอบบนเครื่องนี้เสร็จแล้ว รายการอุปกรณ์จริงยังต้องตรวจรับก่อนรับรองการใช้งานบนสภาพแวดล้อมนั้น ไม่อ้างว่ารองรับทุกเครื่องหรือถูกต้องตามระเบียบทุกกรณี

## ข้อจำกัดที่กำหนดไว้สำหรับ V1

ใช้คนเดียวในเครื่อง สำเนากู้คืนยังไม่ใช่การบันทึกทะเบียน การจองเลขไม่เชื่อมทะเบียนหน่วยงานอื่น การลงชื่อในฟอร์มไม่ใช่ลายเซ็นอิเล็กทรอนิกส์ การสำรองตามรอบต้องเปิดเซิร์ฟเวอร์อยู่ ชุดสำรองก่อนอัปเดตรวมการตั้งค่าส่วนตัวจึงต้องเก็บเป็นส่วนตัว Google Drive ต้องตั้งค่าบัญชีของผู้ใช้และใช้อินเทอร์เน็ต; การตรวจรอบนี้ไม่สร้างหรือส่งเอกสารทดสอบไปยังบัญชี Google จริง
