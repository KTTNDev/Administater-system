# ตรวจระบบรุ่น 1.1.5

เริ่มตรวจ 18 ตุลาคม 2569 · รวมแก้ไขและส่งมอบในรุ่น 1.2.0 วันที่ 21 ตุลาคม 2569

## ข้อผิดพลาดที่ยืนยันและแก้ไข

1. **บันทึกแล้วแต่ยังขึ้นว่ายังไม่ได้บันทึก** — เมื่อชื่อเรื่องมีช่องว่างหัวท้าย เซิร์ฟเวอร์ตัดช่องว่าง แต่ฟอร์มยังเก็บค่าเดิม ทำให้สถานะเปรียบเทียบไม่ตรงกัน แก้ให้รับค่าที่บันทึกจริงกลับเข้าแบบฟอร์ม โดยไม่เขียนทับการเปลี่ยนแปลงที่ใหม่กว่า
2. **เปลี่ยนร่างระหว่างบันทึก** — การกดกลับรายการหรือสร้างร่างใหม่ขณะคำขอบันทึกยังไม่จบอาจทำให้ผลตอบกลับของร่างเก่าไปเปลี่ยนสถานะของร่างใหม่ แก้ให้รอการทำงานเสร็จก่อนสลับร่าง กู้สำเนา รีเฟรช หรือออกจากระบบ และปิดการขยับภาพระหว่างนั้น
3. **ลายเซ็นหรือข้อความวางอิสระตกหล่นเมื่อหน้าหายไป** — เมื่อลดเนื้อหาจนหน้าที่เคยวางภาพไม่มีแล้ว ภาพจะไม่อยู่ในเอกสารส่งออก แก้ให้แจ้งเลขหน้าที่ต้องเลือกใหม่ เก็บภาพไว้ในร่าง และไม่อนุญาตพิมพ์/ส่งออก PDF, Word หรือ Drive จนแก้ตำแหน่ง ทั้งหน้าจอและเส้นทางส่งออกฝั่งเซิร์ฟเวอร์ตรวจเงื่อนไขนี้

4. **preview รวมเนื้อหายาวไว้หน้าเดียว** — iframe อาจเริ่มวัดขณะพื้นที่ยังมีขนาดศูนย์ และโหมดโฟกัสซ่อน preview ด้วย display:none ทำให้การแบ่งหน้าคิดว่าข้อความทั้งหมดพอดี แก้ให้รอหน้ากระดาษมีขนาดก่อนวัด และใช้การซ่อนที่ยังคง layout พร้อมปิดการโต้ตอบ/การเข้าถึงของส่วนที่ซ่อน

## ขอบเขตการตรวจ

- สร้าง แก้ไข บันทึก และเปิดร่างซ้ำทุกแบบฟอร์ม
- เลื่อนแบบฟอร์มและตัวอย่าง กระโดดหัวข้อ หลายขนาดหน้าจอ
- ตาราง เอกสารยาว ส่วนลงนาม ตราประทับ สำเนาคู่ฉบับ และภาษาไทย
- รูปภาพ เอกสารแนบท้าย PDF ลายเซ็น และข้อความวางอิสระ
- ส่งออก PDF และ Word
- ถังขยะ กู้คืน เลขทะเบียน สำรอง/กู้คืนข้อมูล และชุดโปรแกรมพกพา
- งานธุรการ โอนงบ ปฏิทิน จองห้อง ค้นหา ตั้งค่า และการเข้าสู่ระบบเมื่อเปิดใช้งาน

ทดสอบโดยใช้ฐานข้อมูลและพื้นที่เก็บไฟล์ชั่วคราวแยกจากเอกสารผู้ใช้ ไม่ส่งข้อมูลทดสอบขึ้นบัญชี Drive จริง
