# จัดซื้อจัดจ้าง: บิลเดียวถึงคลังลงรับรอบสอง

ปรับปรุง 15 พฤศจิกายน 2569 ใช้ฟอร์มซ้ายและตัวอย่าง A4 ขวาแบบหน้าร่างหนังสือ แม่แบบ D01–D14 ตรวจ SHA-256 จากชุดต้นฉบับ ยกเว้น D10 เป็นแบบสรุปที่ร่างเพิ่มและระบุที่มา เพราะต้นฉบับเป็นภาพ ไม่มีแบบ Word สำหรับร่าง

## ขั้นตอนใช้งาน

1. เลือกจัดซื้อหรือจัดจ้าง กรอกร้านค้า รายการ จำนวน หน่วย ราคาต่อหน่วย และ VAT ให้ตรงบิล ระบบคำนวณยอดและตัวอักษรให้ทั้งชุด หากราคาเสนอต่างจากราคาตกลง เปิดช่องราคาเสนอเพิ่ม
2. เปิดข้อมูลร่วมเฉพาะที่ต้องเติม: ร้านค้า หน่วยงาน งบประมาณ ใบสั่ง และผู้ตรวจรับ วงเงินตัวอักษรอ่านอย่างเดียว เปลี่ยนตามตัวเลขและล้างตาม ไม่ค้างยอดเก่า
3. ระบุเลขและวันที่แต่ละฉบับ ตรวจข้อความประจำและผู้ลงนาม ตัวอย่างขวาจัดหน้าจริงด้วย Microsoft Word หลังหยุดพิมพ์ ระหว่างรอระบุว่ากำลังแสดงตัวอย่างก่อนหน้า
4. เลือกชุดเอกสาร D01–D14 ส่วน D05–D11 เลือกไฟล์ e-GP หรือร่างจากข้อมูลกลางทีละฉบับ สร้าง Word ทั้งชุดที่เลือกร่าง ดาวน์โหลด ZIP หรือรวม PDF A4 ได้
5. กำหนดวันครบสัญญาและงานย่อยพร้อมผู้รับผิดชอบ/งานก่อนหน้า ระบบตรวจงานวนกลับและขั้นก่อนหน้าที่ยังไม่เสร็จ รายการงานเรียงกำหนดสัญญา ยังไม่คำนวณวันทำการหรือแจ้งเตือนภายนอกอัตโนมัติ
6. แนบใบเสนอราคา ใบมอบอำนาจ เอกสารภาษี ภาพ และไฟล์ระบบ เก็บต้นฉบับพร้อม SHA-256 D10 ใช้หลักฐานข้อมูลสาระสำคัญจาก e-GP ส่วน E01 คือข้อมูลสัญญาต้นทาง e-GP ที่แสดงและจับภาพใน e-LAAS
7. พิมพ์ A4 ลงนามจริง สแกนกลับ เลือกฉบับใช้งาน/สแกน ตรวจยืนยันเนื้อหาและลายเซ็น บันทึกผลตรวจรับและค่าปรับตามจริง ดูสิ่งที่ยังขาดก่อนส่งคลัง
8. ส่งชุดตั้งหนี้ → คลังลงรับรอบแรก → คลังส่งเอกสารกลับให้เจ้าของเรื่องดำเนินการต่อ การส่งคืนตามปกติแยกจากตีกลับแก้ไข
9. แนบฎีกา V01 จาก e-LAAS พิมพ์ให้ผู้มีอำนาจลงนาม แนบสแกน ส่งคลังรอบสอง บันทึกเลข/วันที่ลงรับจึงจบงาน ไม่ใช้สถานะจ่ายเงินจริงเป็นเงื่อนไขปิดงานนี้

## ข้อมูลที่กรอกใช้ตรงไหน

| ข้อมูล | เอกสารที่ใช้ |
|---|---|
| รายการ จำนวน หน่วย ราคา | หัวเรื่อง/เนื้อหาที่อ้างรายการ; แยกแถวใน D04/D05/D07/D09 |
| ยอดตกลงและตัวอักษร | D05/D07–D14 เฉพาะฉบับที่แสดงยอด |
| ราคาเสนอ | D07; D05 เมื่อยืนยันใช้เป็นราคาอ้างอิงแล้ว มิฉะนั้นกรอกราคาอ้างอิงเอง |
| งบตั้งไว้และตัวอักษร | D01 และฉบับที่อ้างงบตั้งไว้ แยกจากยอดซื้อ |
| ร้านค้า ที่อยู่ ภาษี ผู้แทน | ฉบับที่อ้างผู้เสนอ ผู้ชนะ คู่สัญญา ใบสั่งและรับเงิน |
| ผู้ลงนาม | ทุกจุดของบทบาทเดียวกันในแม่แบบที่ใช้บทบาทนั้น |
| เลข/วันที่เฉพาะฉบับ | หัวฉบับนั้นและใบต่อบันทึกที่อ้างฉบับนั้น |
| วันที่ใบสั่ง แต่งตั้ง ตรวจรับ | ฉบับและข้อความอ้างอิงที่เกี่ยวข้อง ไม่ใช้วันเดียวแทนทุกเหตุการณ์ |

คลิกช่องเพื่ออ่านคำอธิบายตำแหน่งใช้ข้อมูล หมวดเสริมพับไว้ ฟอนต์ UI ที่เล็กลงไม่เปลี่ยนฟอนต์พิมพ์

## ตัวอย่างและการแก้ไข

- ข้อความจาง “ตัวอย่าง:” หรือ “เช่น” เป็น placeholder ไม่มีค่า ไม่บันทึก ไม่ส่งเข้า Word ต้องกรอกจริงเอง
- งานใหม่เก็บข้อความแม่แบบ แต่ไม่ยืมร้านค้า บิล ราคา เลขหรืองบจากงานก่อน รายชื่อ/หน่วยงานอาจเสนอจากงานล่าสุดที่บันทึก โดยแจ้งให้ตรวจอีกครั้ง
- เงินตัวอักษรคำนวณจากยอดสุทธิ ราคาเสนอ ราคาอ้างอิง งบตั้งไว้และงบคงเหลือ ในตำแหน่งแม่แบบที่มีตัวแปรนั้น ไม่เพิ่มวงเล็บในตำแหน่งที่ต้นฉบับไม่ใช้
- แก้ย่อหน้าเฉพาะฉบับได้ ค่าที่แก้คงไว้จนกดกลับมาใช้ข้อมูลกลาง ต้องตรวจเมื่อเปลี่ยนบิลภายหลัง
- นำ Word ที่แก้ภายนอกกลับเทียบข้อความก่อนเลือกได้ รายการสินค้าแก้ที่บิลกลาง หากโครงสร้างเปลี่ยนจะไม่รวมข้อความให้อัตโนมัติ เลือกใช้ไฟล์นำกลับทั้งไฟล์เพื่อรักษารูปแบบได้
- หลังส่งคลัง ชุดส่งตรึงไฟล์และ SHA-256 แก้เนื้อหาโดยบันทึกตีกลับ/เปิดงานพร้อมเหตุผลและหลักฐาน ฉบับเดิมยังดาวน์โหลดได้

## ขอบเขตและการตรวจ

รองรับกระบวนงานและเอกสารตัวอย่างชุดนี้ ยังไม่เชื่อม API e-GP/e-LAAS และไม่ยืนยันลายเซ็นแทนผู้ใช้ วิธีและข้อยกเว้นต้องพิจารณาเงื่อนไขจริง แม่แบบตัวอย่างไม่ครอบคลุมทุกวิธีหรือสัญญาก่อสร้าง เอกสารยาวแบ่งหน้าได้ ต้องตรวจใบต่อและลายเซ็นก่อนพิมพ์ ไม่รับประกันหนึ่งหน้าเมื่อข้อความยาวขึ้น

หลักฐานทดสอบอยู่ใน `output/procurement-suite/qa` ได้แก่ Word/PDF จริง 14 ฉบับ ชุดพิมพ์ A4 การส่งคลังจนปิดรอบสอง และหน้าจอมือถือ 390 px ใช้ฐานแยกจากงานจริง ทดสอบอัตโนมัติครอบคลุมเงิน/ตัวอักษร ผูกข้อมูล ไฟล์/สถานะข้ามขั้น ตรึงชุดส่ง Word นำกลับ และสำรองกู้คืน
