# จัดช่วงข้อความและบรรทัดในเนื้อหา

ในช่องเนื้อหาที่มีตัวแก้ไขข้อความ กด **โหมดจัดข้อความแบบ Word** เพื่อเปิดการจัดรูปแบบโดยเลือกข้อความบนหน้าจอ

- **Enter / ย่อหน้าใหม่**: เริ่มย่อหน้าใหม่และใช้ระยะย่อหน้าของแบบหนังสือ
- **Shift+Enter / ขึ้นบรรทัดใหม่**: ขึ้นบรรทัดภายในย่อหน้าเดิม ไม่เพิ่มระยะย่อหน้าอีกครั้ง
- **หัวข้อ**: เปลี่ยนย่อหน้าที่เคอร์เซอร์อยู่เป็นหัวข้อ ตัวหนาและไม่ย่อหน้า; กด **เนื้อหา** เพื่อกลับ
- เลือกคำหรือประโยคภายในย่อหน้าเดียว แล้วเลือก **ระยะอักษร (pt)** และกด **ใช้กับข้อความที่เลือก**
  ค่าติดลบบีบระยะ ค่าบวกขยาย และ 0 คือปกติ ใช้ค่าทีละน้อยแล้วตรวจพรีวิวด้านขวา
- ตัวหนาใช้ปุ่มหรือ Ctrl+B ได้ รูปแบบมีผลเฉพาะข้อความที่เลือก

โหมดข้อความเดิมยังใช้แทรกตารางได้ เมื่อสลับกลับจะเห็นรหัสจัดรูปแบบ เช่น
`[space=-0.3]ข้อความ[/space]` และ `## หัวข้อ` บรรทัดย่อยเก็บเป็น U+2028
ร่างเก่าที่ใช้ newline เป็นย่อหน้ายังคงความหมายเดิม

ตำแหน่งบรรทัดขึ้นกับฟอนต์ ความกว้าง และโปรแกรมที่เปิด Word อาจตัดบรรทัดต่างจากพรีวิวบ้าง
ค่าระยะอักษรส่งออกเป็น Word character spacing ที่แก้ต่อได้ และบรรทัดย่อยเป็น Word line break
ไม่ได้ส่งออกเป็นภาพของข้อความ ไม่ปรับขนาดทั้งเอกสารเพื่อบังคับให้ลงหนึ่งหน้า

## จุดพัฒนาต่อ

- `src/lib/body-typography.ts`: parser ที่ escape ข้อความ และแปลง DOM เป็นรูปแบบเก็บข้อมูล
- `src/components/word-body-editor.tsx`: เลือกช่วง เคอร์เซอร์ และคำสั่งแก้ข้อความ
- `src/components/body-editor.tsx`: สลับโหมดเดิมกับโหมดจัดข้อความ
- `src/lib/render-document.ts`: บรรทัดย่อยและ heading ในตัวอย่าง/PDF
- `src/lib/word-layout.ts` และ `src/lib/word.ts`: เก็บ line break และ spacing ใน DOCX

ทดสอบกับภาษาไทย ทั้ง newline ที่เบราว์เซอร์เก็บใน text node และ BR; อย่าอาศัยเฉพาะ keyup
เพราะ input จาก IME/วิธีพิมพ์บางชนิดไม่เกิด keyup แบบปุ่มอักษรทั่วไป
