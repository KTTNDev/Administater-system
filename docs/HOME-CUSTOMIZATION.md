# ปรับแต่งหน้าหลัก

ไปที่ **ตั้งค่า → ปรับแต่งหน้าหลัก** ค่าที่เปลี่ยนจะแสดงในตัวอย่างก่อน และเริ่มใช้จริงเมื่อกด **บันทึกหน้าหลัก**

- เพิ่มทางลัดจากเมนูของระบบได้สูงสุด 16 รายการ เปลี่ยนชื่อปุ่มและหน้าปลายทางได้
- เลือกรายการทางซ้ายแล้วกดลูกศรขึ้น/ลงเพื่อเรียงลำดับ เอาเครื่องหมายถูกออกเพื่อซ่อนโดยยังเก็บการตกแต่งไว้ หรือกดถังขยะเพื่อลบทางลัด
- เลือกโทนสี ภาพประกอบ สีพื้น หรืออัปโหลดรูปของตนเอง พร้อมปรับความเข้มและตำแหน่งภาพ
- ส่วนหัวเลือกภาพชายฝั่ง สีพื้น หรือรูปส่วนตัวได้ รวมถึงชื่อที่แสดง การเคลื่อนไหวพื้นหลัง นาฬิกา ข้อความความสามารถระบบ และขนาดการ์ด
- เปิด/ปิดแถบสรุปงาน รายการงาน โครงการ และทางลัดเลือกแบบหนังสือได้
- **ยกเลิกการแก้ไข** กลับไปค่าที่บันทึกไว้ **คืนค่าเริ่มต้น** คืนหน้าตาระบบเดิมในตัวอย่าง ต้องกดบันทึกอีกครั้งจึงใช้จริง

รูปที่รองรับ: JPG, PNG, WebP ไม่เกิน 5 MB และไม่เกิน 25 ล้านพิกเซล ระบบย่อให้ไม่เกิน 960 × 640 แปลงเป็น WebP และลบข้อมูลประกอบภาพ หากรูปย่อยังใหญ่เกินกำหนด ระบบจะแจ้งให้เลือกรูปใหม่แทนการตัดทิ้ง

ค่าหน้าหลักใช้ร่วมกันในโปรแกรมเครื่องนี้ เก็บที่ตาราง `home_layout` ในฐานข้อมูล SQLite รูปถูกเก็บในข้อมูลชุดเดียวกัน ไม่มีการโหลดภาพจากเว็บไซต์ภายนอก รวมตารางนี้ในชุดสำรองอัตโนมัติ/ด้วยมือและชุดที่ซิงก์ Drive ผ่านระบบสำรองเดิม การนำชุดสำรองนี้ไปกู้คืนต้องใช้โปรแกรมรุ่นที่รองรับตาราง `home_layout` หรือใหม่กว่า ไม่รวมรหัสผ่านและข้อมูลเชื่อมต่อ Google

การเปลี่ยนหน้าหลักไม่เปลี่ยนไซด์บาร์ ไม่ลบข้อมูล ไม่แก้แบบหนังสือหรือ preview/PDF/Word หากซ่อนทางลัดทั้งหมด หน้าหลักยังมีปุ่มไปตั้งค่าและไซด์บาร์ให้กลับมาแก้ได้

สำหรับผู้พัฒนา: `lib/home-layout.ts` เป็น schema/ค่าเริ่มต้น → `lib/home-layout-db.ts` อ่านเขียนพร้อม version ป้องกันทับข้อมูลจากหลายหน้าต่าง → `app/home-layout-actions.ts` ตรวจสิทธิ์และย่อรูป → `components/home-layout-settings.tsx` ตัวแก้ไข → `components/home-shortcuts.tsx` การ์ดจริงและตัวอย่าง → `components/workdesk.tsx` ประกอบหน้า Home เก็บ CSS เฉพาะหน้าระบบที่ `app/home-layout.css` โดยไม่แตะ renderer เอกสาร

## พื้นหลังส่วนหัวทุกเมนู และการเลื่อนภาพ

เปิด **ปรับแต่งหน้าหลัก → พื้นหลังส่วนหัวแต่ละเมนู** เลือกเมนูที่จะปรับ แล้วเลือกสีพื้น ภาพประกอบ หรือรูปส่วนตัว ตั้งค่าแยกได้ทุกเมนู รวมถึงส่วนหัวหน้าจัดทำร่างหนังสือ ส่วน Home ใช้ตัวเลือกเดิมใน **ส่วนหัวและองค์ประกอบหน้าหลัก**

ภาพการ์ดและภาพส่วนหัว Home มีตัวเลื่อนเช่นเดียวกัน: ลากภาพในกรอบตัวอย่าง หรือใช้แถบ **ซ้าย–ขวา / บน–ล่าง / ซูม** หากภาพพอดีกับกรอบในแกนใด แกนนั้นจะเลื่อนไม่ได้จนกว่าจะซูมเพิ่ม ปุ่ม **จัดภาพกึ่งกลาง** คืนค่า 50%, 50%, ซูม 100% เมื่อโฟกัสกรอบภาพ ใช้ปุ่มลูกศรเลื่อนทีละ 1% หรือ Shift+ลูกศรทีละ 5% ได้

รูปอัปโหลดแสดงเต็มกรอบด้วยการตัดส่วนเกิน โดยรักษาสัดส่วน ไม่ยืดภาพ ตัวอย่างจะปรับตามความกว้างพื้นที่ตั้งค่า และหน้าจอจริงจะปรับตามขนาดอุปกรณ์ จุดโฟกัสและซูมที่บันทึกยังใช้ค่าเดียวกันทุกขนาดหน้าจอ

กด **บันทึกหน้าหลัก** เพื่อบันทึกทั้งการ์ด Home และพื้นหลังส่วนหัวเมนูทั้งหมด **คืนค่าเฉพาะเมนูนี้** คืนเฉพาะส่วนหัวที่เลือกในตัวอย่าง ส่วนปุ่มคืนค่าเริ่มต้นด้านล่างจะคืนการตกแต่งทั้งหมด เมื่อรูปยังไม่ครบ ระบบจะไม่บันทึกหรือทิ้งงานเดิม

ค่าตำแหน่งและภาพอยู่ใน `home_layout` และรวมในชุดสำรองเดิม จำกัดข้อมูลการตกแต่งรวมไม่เกิน 4 MB ไม่รวมข้อมูลเชื่อมต่อหรือรหัสผ่าน ส่วน UI นี้ไม่แก้ข้อความ หน้ากระดาษ preview หรือ PDF/Word

โค้ดเพิ่มเติม: `lib/image-focus.ts` คำนวณกรอบภาพและพิกัดการลาก, `components/image-focus-editor.tsx` ควบคุมด้วยเมาส์/สัมผัส/คีย์บอร์ด, `components/menu-header-settings.tsx` เลือกส่วนหัวแต่ละเมนู และ `app/header-appearance.css` แสดงเฉพาะส่วนหัวที่เปิดใช้การตกแต่ง
