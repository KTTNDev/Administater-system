# ย้อนกลับ หน้าหลัก และโหมดเต็มจอ

แถบด้านบนมีปุ่มลูกศร **ย้อนกลับหน้าก่อนหน้า** และรูปบ้าน **ไปหน้าหลัก** ใช้ได้ทุกเมนู ลูกศรจำลำดับเมนูภายในระบบครั้งที่เปิดอยู่นี้ สูงสุด 40 หน้า ไม่ย้อนออกไปเว็บไซต์อื่น ถ้าเปิดเมนูจากลิงก์โดยตรงและยังไม่มีประวัติ ปุ่มย้อนกลับจะพาไป Home

กดรูปขยายหน้าจอด้านบน หรือปุ่ม **เต็มจอ** บน Home เพื่อเปิดเต็มจอ ขณะเต็มจอให้เลือกหน้าอื่นจากไซด์บาร์เดิม บนจอแคบระบบจะเปิดลิ้นชักเมนูให้เมื่อเข้าเต็มจอ เลือกหน้าแล้วเปิดอีกครั้งได้จากปุ่มเมนู กดปุ่มออกจากโหมดเต็มจอในแถบด้านบนหรือใช้วิธีออกของเบราว์เซอร์ หากใช้ F11 แถบด้านบนและเมนูปกติยังใช้งานได้

ปุ่มเปลี่ยนหน้าจะใช้การตรวจข้อมูลที่ยังไม่บันทึกชุดเดียวกับไซด์บาร์ ยกเลิกคำถามเพื่อกลับไปทำงานต่อ หรือยืนยันเมื่อต้องการออกจากหน้านั้น การออกจากเต็มจอไม่ได้เปลี่ยนเอกสาร

โค้ด: `lib/workspace-location.ts` เก็บลำดับเมนูและคำนวณย้อนกลับ → `components/workspace-page-navigation.tsx` แสดงปุ่มและติดตาม Fullscreen API → `components/workspace.tsx` ตรวจงานที่ยังไม่บันทึกก่อนเปลี่ยนหน้า CSS แยกที่ `app/workspace-navigation-controls.css` โดยไม่แก้หน้าเอกสารหรือไฟล์ส่งออก
