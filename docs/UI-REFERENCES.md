## สิ่งที่เปลี่ยนใน 1.2.4

- หน้าค้นหาเมนู: สีและฟอนต์เดียวกับระบบ ล้างคำค้นได้ มีทางลัดหนังสือภายนอกและบันทึกข้อความ
- ผลค้นหา: ไอคอนช่วยแยกประเภท ชื่อเด่น คำอธิบายรอง หัวและช่องค้นหาไม่เลื่อนไปพร้อมผลลัพธ์
- Ctrl K เปิด/ปิด, ลูกศรเลือก, Home/End ไปต้น/ท้าย, Enter เปิด และ Esc ปิด คืนจุดโฟกัสเดิม
- ไม่เปิดหน้าค้นหาทับ native dialog หรือ modal อื่นที่กำลังใช้ และไม่รับคำสั่ง Enter ระหว่าง IME composition
- เมนูหลักใหญ่ขึ้นเล็กน้อย แถวเอกสารเห็นสีเน้นเมื่อใช้คีย์บอร์ด ปุ่มจัดการมีพื้นที่กดเพิ่ม
- กระจกฝ้าใช้ที่ส่วนหัวและฉากหลังหน้าค้นหา มีพื้นทึบเมื่อไม่รองรับหรือเลือก reduced transparency
- ไม่มี dependency ใหม่ ไม่มีการเปลี่ยนฐานข้อมูล/เนื้อหา/ตัวจัดหน้า PDF/Word ไม่มีการส่งคำค้นไปภายนอก

## ข้อจำกัดและการเลือก

เอฟเฟกต์เป็นส่วนเสริม การเปิดปิดและโฟกัสทำงานทันที ไม่รอแอนิเมชัน
CSS fallback ต้องอ่านและใช้งานได้เมื่อไม่รองรับ backdrop-filter; forced-colors ใช้สีระบบ
การอ้างอิงแนวคิดไม่ได้หมายถึงติดตั้งหรือคัดลอกโค้ดจากทั้ง 10 โครงการ และไม่ได้รับรองว่าไลบรารีใหม่ทุกตัวเหมาะกับทุกเครื่อง
เอกสารจริงกับ preview อยู่ในระบบจัดหน้าเดิมและไม่ได้ใช้ glass, 3D หรือ motion ของส่วนติดต่อ
