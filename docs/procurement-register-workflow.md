# ลายแทงและกระบวนงานจัดซื้อจัดจ้าง

## เริ่มงาน

1. เลือกจัดซื้อหรือจัดจ้าง ระบบเปิดแท็บ **ลายแทงเลขเอกสาร** ก่อน
2. ใส่ชื่อเรื่องสั้นและปีงบประมาณ แล้วบันทึกได้ทันที ยังไม่ต้องมีร้านค้าหรือบิลครบ
3. เลือกฉบับ บันทึกเลขที่จองจากสมุดคุมจริง ระบุเจ้าของทะเบียน ชุดเลข ปีทะเบียน และวันที่แผน ทำครบครั้งเดียวหรือทยอยรายวันได้
4. เมื่อทราบวันที่เอกสารจริง ให้กรอกช่องวันที่ยืนยันและยืนยันใช้เลข การจองหรือใช้เลขไม่ใช่การอนุมัติ ลงนาม ส่งมอบ หรือตรวจรับ
5. เปิดแท็บ **ข้อมูลบิลและเอกสาร** กรอกร้านค้า รายการ จำนวน ราคา และภาษีครั้งเดียว เอกสารที่ผูกข้อมูลกลางใช้ชุดเดียวกัน
6. ตรวจ Preview สร้างฉบับ พิมพ์เสนอเซ็น เก็บสแกน และยืนยันตรวจทานตามลำดับ

ปีงบประมาณแยกจากปีทะเบียนหนังสือ เลขทะเบียนประกาศแยกจากเลขหนังสือแจ้งผู้ชนะ หากแบบประกาศไม่มีช่องเลข ให้เก็บเป็นเลขทะเบียนกำกับโดยไม่พิมพ์เลขนั้นบนประกาศ

เลขที่บันทึกแล้วไม่แก้ทับเป็นเลขอื่น ให้ยกเลิกพร้อมเหตุผลแล้วเพิ่มรายการใหม่ เลขที่ยกเลิกและฉบับพิมพ์ซ้ำคงอยู่ในประวัติ ระบบตรวจเลขซ้ำภายในฐานข้อมูลเดียวกัน รวมเลขไทย/อารบิกและทะเบียนหนังสือทั่วไปที่ตรงประเภท หน่วยงาน ชุดเลข และปี การใช้ฐานข้อมูลหลายสำเนาแยกกันไม่ใช่ทะเบียนกลางร่วมกัน

## อ่านลายแทง TXT

เลือกปี พ.ศ. ของวันที่ในไฟล์ก่อนเลือก TXT ระบบแสดงชื่อเอกสาร เลข และวันที่เพื่อเทียบ ชุดข้อความนี้เป็นข้อมูลรอทบทวน ไม่เขียนทับเลขในเอกสารและไม่จองเลขแทนสมุดคุม รายการที่ยังไม่มีแบบ เช่น บันทึกต่อรองราคา แสดงให้เห็นโดยไม่สร้างข้อความหรือเลขขึ้นเอง

## เอกสารและแหล่งที่มา

- หนังสือแจ้งผู้ชนะลงนามแยกจากประกาศผู้ชนะ เป็นหนังสือภายนอก
- รายงานขอซื้อ/ขอจ้าง e-LAAS และรายงานสัญญา/ข้อตกลง e-LAAS เก็บคนละหมวด
- ภาพหน้าจอข้อมูลสัญญา e-GP ที่แสดงใน e-LAAS เป็นหลักฐานเสริม เปิดใช้เมื่อมีภาพแยกจากรายงาน
- ภาพประกอบเป็นของงานปัจจุบัน ไม่คัดลอกภาพสินค้าจากแม่แบบเดิมมาเป็นหลักฐาน
- ใบตรวจรับงานใหม่ตั้งต้นสองชุดพิมพ์ ใช้เลขเดียวกัน
- D05–D11 ยังคงเลือกไฟล์ระบบหรือร่างจากข้อมูลกลางได้ ส่วน PDF ต้นทางและสแกนไม่ถูกเปลี่ยนฟอนต์หรือข้อมูล
- แม่แบบอ้างอิงส่วนบุคคลไม่รวมใน Git ต้องติดตั้งหรือย้ายไปพร้อมฐานข้อมูลสำรอง

## ช่วงคลัง

ตรวจรับและรายงานครบ → ส่งตั้งหนี้ → คลังลงรับรอบแรก → คลังแจ้งและคืนเอกสาร → บันทึกขออนุมัติเบิกเงินพร้อม PDF ฎีกา e-LAAS → เสนอเซ็นและสแกน → ส่งรอบสอง → คลังลงรับรอบสองและปิดงาน

บันทึกขอเบิกเงินไม่ใช่เงื่อนไขส่งตั้งหนี้รอบแรก แต่ต้องมีพร้อมฎีกาในรอบสอง หลังคลังคืนเอกสารแก้ได้เฉพาะข้อมูลของบันทึกขอเบิกและฎีกา ข้อมูลบิลและชุดตั้งหนี้เดิมตรึงไว้ หากจำเป็นต้องแก้ข้อมูลชุดแรกให้เปิดแก้ไขพร้อมเหตุผลตามขั้นตอน

งานเก่าที่ส่งคลังหรือปิดแล้วใช้ไฟล์และหลักฐานที่ตรึงไว้ ไม่สร้างใหม่เพียงเพราะเปิดดู แม่แบบใหม่ใช้กับร่างที่สร้างใหม่ ประวัติการส่งและไฟล์เดิมยังอยู่

## Preview และ Word

Preview และไฟล์พิมพ์ใช้การจัดหน้าจาก Microsoft Word บน Windows ต้องเปิด Word ได้ตามปกติ ระบบใช้ instance สำหรับจัดหน้าโดยเฉพาะ หาก Word เริ่มไม่ได้จะพักคิวชั่วคราวและแสดงข้อผิดพลาด ไม่แสดงภาพร่างเก่าเป็นฉบับล่าสุด

เอกสารที่ระบบสร้างใช้ Sarabun และแปลงตัวเลขในข้อความเป็นเลขไทยจริง รวมส่วนเลขหน้าของใบต่อ ไฟล์จากหน่วยงาน ร้านค้า e-GP และ e-LAAS เก็บต้นฉบับเดิม
