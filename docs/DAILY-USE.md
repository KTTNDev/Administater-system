# เปิดระบบสำหรับใช้งานประจำ — รุ่น 1.5.0

## เปิดใช้งานบนเครื่อง

1. ดับเบิลคลิก `Open-Sarabun.cmd` ในชุดโปรแกรมที่สร้างแล้ว ระบบเปิดที่ `http://127.0.0.1:3000`
2. หากต้องการทางลัด ให้เปิด `Create-Shortcuts-Sarabun.cmd` จากโฟลเดอร์เดียวกัน
3. ใช้ปุ่มรีเฟรชบนแถบด้านบนเมื่อจำเป็น และบันทึกงานก่อนปิดโปรแกรม
4. หยุดเซิร์ฟเวอร์ด้วย `Stop-Sarabun.cmd` ก่อนย้ายโฟลเดอร์หรือส่งออกชุดโปรแกรม

การใช้งานปกติไม่ต้องรัน npm และไม่ต้อง build ทุกครั้ง ค่าเริ่มต้นของระบบผู้ใช้คนเดียวเปิดเข้าใช้งานได้โดยไม่ล็อกอิน ดู [เริ่มใช้และย้ายเครื่อง](../QUICK-START-TH.md) สำหรับชุด Clean / Personal / Update

## สำหรับผู้พัฒนา

ใช้ `npm run dev` เฉพาะตอนแก้โค้ด หลังแก้เสร็จให้สร้างชุดใช้งานด้วย `scripts/build-desktop.mjs` แล้วหยุดและเปิดตัวโปรแกรมใหม่ ตรวจเลขรุ่นที่หน้าตั้งค่าเพื่อป้องกันการเปิดชุดเก่าค้างอยู่ ดู [การตั้งเครื่องพัฒนา](NEW-PC-DEVELOPMENT.md)

## เมื่อต้องการเปิดระบบล็อกอิน

ตั้ง `SARABUN_REQUIRE_LOGIN=true`, `APP_PASSWORD` อย่างน้อย 12 ตัวอักษร และ `SESSION_SECRET` อย่างน้อย 32 ตัวอักษรใน `.env.local` แล้วเริ่มเซิร์ฟเวอร์ใหม่ หากมี SESSION_SECRET อยู่แล้วให้รักษาค่าเดิมที่ใช้เข้ารหัสข้อมูล Drive ไว้ ห้ามนำไฟล์นี้ขึ้น GitHub การเปลี่ยนรหัสผ่านไม่ยกเลิกเซสชันเดิมทันที ระบบนี้ยังเป็นบัญชีผู้ปฏิบัติงานร่วม ไม่ใช่ระบบหลายบัญชี

## สำรองและกู้คืน

เปิดหน้าตั้งค่า → พื้นที่จัดเก็บและสำรองข้อมูล ตั้งรอบอัตโนมัติหรือกดสำรองตอนนี้ ตรวจวันที่สำรองสำเร็จล่าสุดได้ในหน้าเดียวกัน

การกู้คืนจากหน้าเว็บต้องตรวจรายการและยืนยันก่อน ระบบสร้างสำรองข้อมูลปัจจุบันก่อนแทนข้อมูลธุรกิจด้วยชุดที่เลือก โดยเก็บการตั้งค่าของเครื่องเดิมไว้ การกู้คืนอาจย้อนทะเบียนเลขด้วย จึงต้องตรวจเลขที่ออกหลังวันที่สำรองก่อนใช้งานต่อ ดู [สำรองและกู้คืน](BACKUP-RESTORE.md)

## Google Drive

ตั้งค่า OAuth Client แบบ Web application และเชื่อมบัญชีในหน้าตั้งค่าของโปรแกรม โดย Redirect URI ต้องตรงกับ `http://127.0.0.1:3000/api/google/callback` การเชื่อม Google Drive ในแชทไม่ใช่การเชื่อมบัญชีให้โปรแกรมนี้ ดู [คู่มือ Google Drive](GOOGLE-DRIVE.md)

โครงสร้างคลังกฎหมาย งานประจำ และโครงการรวมอยู่ในชุดสำรองฐานข้อมูล ส่วนการอัปโหลด PDF แยกรายการไม่ใช่การสำรองทั้งระบบ
