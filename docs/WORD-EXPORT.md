# ส่งออก Word รุ่น 1.1.1

เปิดร่างแล้วกด **ดาวน์โหลด Word** ข้างปุ่ม PDF ระบบบันทึกค่าล่าสุดก่อนสร้างไฟล์ `.docx` ใช้ได้กับหนังสือทั้ง 13 แบบ และบันทึกที่สร้างจากคำขอโอนงบประมาณ

## สิ่งที่แก้ไขต่อได้

- ข้อความ ตัวหนา หัวข้อขีดเส้นใต้ ชื่อและตำแหน่งผู้ลงนาม
- ตาราง Word พร้อมหัวตารางและข้อมูลในแต่ละช่อง
- เอกสารแนบท้ายที่สร้างในระบบและคำบรรยายภาพ
- รูปภาพ ตราประทับ และกล่องข้อความโปร่งใสเป็นวัตถุลอย

ฟอนต์ TH Sarabun New ฝังในไฟล์ การสร้างไฟล์ไม่ต้องติดตั้ง Microsoft Word บนเครื่องต้นทาง ใช้ Edge/Chrome เหมือนตัวส่งออก PDF

PDF ที่อัปโหลดแนบจะรวมเป็นภาพแต่ละหน้า รองรับรวมไม่เกิน 200 หน้า จึงแก้ข้อความภายใน PDF แนบโดยตรงไม่ได้ เมื่อเลือกสำเนาคู่ฉบับ ระบบส่งออกทั้งต้นฉบับและสำเนาพร้อมชุดเอกสารแนบของแต่ละฉบับ

## ขอบเขต

Word จัดบรรทัดและหน้าใหม่ได้เมื่อผู้รับแก้เนื้อหา ควรตรวจทุกหน้าก่อนพิมพ์ การแก้ไขไฟล์ที่ดาวน์โหลดไม่ย้อนกลับเข้าร่างในระบบโดยอัตโนมัติ ระบบยังไม่รองรับนำเข้า Word เพื่อแก้ร่างเดิม

คำสั่งตรวจซ้ำสำหรับผู้พัฒนา:

```powershell
node node_modules/vitest/vitest.mjs run --maxWorkers=2 --testTimeout=20000 --hookTimeout=30000
npm run typecheck
npm run desktop:build
node scripts/test-release.mjs tests/e2e/word-export.spec.ts tests/e2e/attachments-ui.spec.ts --reporter=line
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-word-render.ps1
```

การตรวจด้วย Word ต้องติดตั้ง Microsoft Word บนเครื่องทดสอบ ส่วนการดาวน์โหลดจากโปรแกรมไม่ต้องติดตั้ง Word ไฟล์ตัวอย่างและผลละเอียดเก็บใน `output/word-check/`, `output/word-unit-verified.log` และ `output/word-browser-verified.log` ซึ่งไม่ส่งขึ้น GitHub

## การจัดภาษาไทย รุ่น 1.1.1

ย่อหน้าเนื้อหาใช้ Thai Distributed ข้อความคงเป็นย่อหน้าเดียวแม้ยาวข้ามหน้า ไม่มีการแทรกอักขระแบ่งคำหรือ Shift+Enter เพื่อเลียนแบบบรรทัดในตัวอย่าง หัวเรื่อง วันที่ และลายเซ็นยังคงการจัดแนวตามแบบหนังสือ ตัวหนาและขีดเส้นใต้ยังแก้ไขได้

ระบุภาษาไทยและปิดตรวจสะกด/ไวยากรณ์เฉพาะข้อความที่ส่งออก จึงไม่แสดงเส้นเตือนใต้คำ แต่ไม่ได้ตรวจหรือแก้คำสะกดให้ ผู้ใช้สามารถเปิดการตรวจสะกดกลับใน Word ได้ การตัดคำและช่องไฟยังขึ้นกับชุดภาษาไทยและรุ่น Word ของเครื่องที่เปิดไฟล์ โดยเฉพาะเครื่องที่ไม่มีพจนานุกรมภาษาไทย

ไฟล์ที่ดาวน์โหลดไว้ก่อนอัปเดตไม่เปลี่ยนตาม ต้องดาวน์โหลด Word ใหม่จากร่างเดิม

ผลตรวจ 13 ตุลาคม 2569: ชุดทดสอบ 124 รายการ และการดาวน์โหลดผ่านหน้าโปรแกรม 14 รายการผ่านทั้งหมด สร้างโปรแกรมรุ่น 1.1.1 สำเร็จ ตรวจไฟล์ด้วย Microsoft Word 16.0 แล้วพบว่าระบุย่อหน้าและภาษาได้ตามข้อกำหนด แต่เครื่องทดสอบไม่มีพจนานุกรมไทย (มีเฉพาะอังกฤษ) จึงยังพบช่องไฟยืดและการตัดคำที่ไม่เหมาะสมบางบรรทัด ไม่ถือว่าการตัดคำบนเครื่องนี้ได้รับการยืนยันสมบูรณ์
