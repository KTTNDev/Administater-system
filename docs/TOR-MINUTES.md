# รายงานการประชุม TOR — ชุดงานที่กู้กลับมา D:\sarabun (26 ตุลาคม 2569)

## เริ่มใช้งาน

1. เลือก **แบบหนังสือราชการ → รายงานการประชุม**
2. ในข้อมูลการประชุม เลือกแม่แบบ **ประชุม TOR / คุณลักษณะเฉพาะพัสดุ** หรือ **ประชุม TOR / ขอบเขตงานจ้าง** แล้วกด **ใช้แม่แบบนี้**
3. กรอกชื่อโครงการ ครั้งที่ วันที่ สถานที่ และเวลา เรียงตามส่วนของแบบฟอร์มเดิม
4. กรอกรายชื่อ ตำแหน่งราชการ หน้าที่ และสถานะของผู้ประชุม ช่องลายมือชื่อในตารางจะเว้นว่างไว้สำหรับลงนาม ผู้ไม่มาประชุมระบุเหตุผลได้
5. กรอกข้ออภิปรายในแต่ละวาระ วาระพิจารณา TOR มีข้อมูลคำสั่งแต่งตั้ง วงเงิน แหล่งอ้างอิง และหัวข้อรายละเอียดที่เปิดแก้ทีละหัวข้อได้
6. ในแต่ละวาระ กด **เพิ่มผู้พูด / ข้อซักถาม** ได้หลายครั้ง (สูงสุด 50 รายการต่อวาระ) แต่ละรายการมีชื่อ บทบาท และข้อความของตัวเอง เลื่อนขึ้น–ลงหรือลบได้ หากคนเดิมพูดอีกครั้งให้เพิ่มรายการใหม่เพื่อคงลำดับบทสนทนา แล้วบันทึกมติจริงแยกต่างหาก
7. เลือกผู้จดจากรายชื่อ หรือพิมพ์เอง เพิ่มกรรมการและประธานผู้ลงนามท้ายรายงานได้ ชื่อ ตำแหน่ง และบทบาทยังแก้เองได้ทุกช่อง
8. ตรวจตัวอย่าง A4 บันทึกร่าง แล้วส่งออก PDF ผ่านปุ่มเดิม (ชุดงาน D: ที่นำกลับมายังไม่มีระบบส่งออก Word)

## ปรับแม่แบบได้อย่างไร

- มีแม่แบบประชุมทั่วไป และ TOR สองแบบ หัวรายงานและหัวข้อวาระแก้ได้ทั้งหมด
- ถ้ามีวาระอยู่แล้ว ปุ่มเพิ่มแม่แบบจะต่อท้ายวาระเดิม หากเลือกแทนที่วาระเดิม ระบบถามยืนยันก่อนลบข้ออภิปรายและมติเดิม
- การเปลี่ยนแม่แบบไม่ลบรายชื่อหรือรายละเอียด TOR ที่เคยกรอกไว้ ถ้าจะเปลี่ยนจากงานซื้อเป็นงานจ้างในร่างเดิม ให้ตรวจและปรับชื่อหัวข้อ TOR ให้ตรงงานด้วย
- เปลี่ยนเป็นโหมดวาระแล้ว ข้อความอิสระเดิมยังเก็บอยู่ สามารถสลับโหมดกลับได้ แต่แสดงในเอกสารเฉพาะโหมดที่เลือก
- หัวข้อ TOR เพิ่ม ลบ แก้ และเลื่อนลำดับได้ ข้อความรองรับตัวหนาและตารางผ่านเครื่องมือเนื้อหาเดิม
- เลือกวาระที่จะแสดงชุดรายละเอียด TOR ได้ครั้งละหนึ่งวาระ เมื่อย้ายไปวาระอื่น รายละเอียดชุดเดิมจะตามไปด้วย
- ผู้พูดและผู้ลงนามเพิ่มได้ตามการประชุมจริง โดยไม่จำเป็นต้องมีเท่ากับตัวอย่าง
- เพิ่มไฟล์ PDF / ภาพเป็นไฟล์แนบ และเพิ่มภาคผนวกภาพประกอบได้เหมือนเครื่องมือเอกสารเดิม

ขอบเขตข้อมูลต่อร่าง: 50 วาระ, 60 รายชื่อ, 30 หัวข้อ TOR, 50 ข้อความผู้พูดต่อวาระ และ 20 ผู้ลงนามเพิ่มเติม (นอกจากผู้จด)

## องค์ประกอบที่นำมาปรับจากตัวอย่าง 6 หน้า

| องค์ประกอบ | ตำแหน่งในระบบ |
| --- | --- |
| หัวรายงาน โครงการ ครั้งที่ วัน เวลา สถานที่ | ข้อมูลการประชุม |
| ตารางผู้มาประชุมและช่องลายมือชื่อ / ผู้ไม่มาประชุม | ผู้เข้าประชุมแบบตาราง |
| คำสั่งแต่งตั้ง หน่วยงาน วงเงินและข้อมูลอ้างอิง | ข้อมูลประกอบการพิจารณา TOR |
| วาระประธานแจ้ง รับรองรายงาน เรื่องทราบ พิจารณา และอื่น ๆ | วาระที่เพิ่มโดยแม่แบบ |
| ที่มา วัตถุประสงค์ คุณลักษณะ ข้อเสนอ ส่งมอบ ตรวจรับ จ่ายเงิน รับประกัน ค่าปรับ | หัวข้อ TOR ที่ปรับเพิ่มหรือลบได้ |
| การอภิปรายและข้อซักถามของกรรมการ | ผู้พูดในวาระ พร้อมช่องบทบาทและข้อความ |
| มติ เวลาปิดประชุม ผู้จด กรรมการ ประธาน | มติในวาระและส่วนท้ายรายงาน |

ใช้ฟอนต์ TH Sarabun New และตัวจัดหน้า A4 ของระบบเดิม ชื่อผู้พูดแสดงเป็นหัวข้อก่อนข้อความเพื่ออ่านและแก้ได้สะดวก ไม่เลียนแบบการแบ่งคอลัมน์ในเอกสารสแกนทุกจุด ไม่คัดลอกชื่อบุคคล ราคา สเปกสินค้า หรือเงื่อนไขสัญญาในตัวอย่างมาเป็นข้อมูลจริงของแม่แบบ

แม่แบบเตรียมเฉพาะโครงสร้าง มติและเนื้อหาว่างให้กรอกตามการประชุมจริง การใช้แม่แบบไม่ใช่การรับรองความถูกต้องของสเปกหรือเงื่อนไขจัดซื้อจัดจ้าง ต้องตรวจตามโครงการและอำนาจหน้าที่จริงก่อนออกเอกสาร

## สำหรับผู้พัฒนา

- `src/lib/minutes-presets.ts`: รายการแม่แบบ ชื่อวาระและหัวข้อเริ่มต้น การเพิ่มต่อท้าย/แทนที่
- `src/lib/document.ts`: schema ที่ให้ค่าเริ่มต้นเพื่ออ่านร่างเก่า, การตรวจข้อมูล, ลำดับเนื้อหาที่ใช้ร่วมกัน
- `src/components/minutes-details.tsx`: ตัวเลือกแม่แบบ รายชื่อ หัวข้อ TOR และผู้ลงนาม
- `src/components/minutes-editor.tsx`: วาระ ผู้พูด และวาระที่ใช้ชุด TOR
- `src/components/minutes-speeches-editor.tsx`: เพิ่ม แก้ไข ลบ และจัดลำดับคำอภิปรายหลายคนต่อวาระ
- `src/components/workspace.tsx`: ผูกเข้ากับแบบฟอร์มประชุมและส่วนเอกสารแนบ
- `src/lib/render-document.ts`: ตารางผู้เข้าประชุม บล็อกลงนาม การแบ่งหน้า และหัวข้อที่อยู่กับเนื้อหา
- `scripts/open-local.mjs`: เปิดชุดงานจากโฟลเดอร์นี้ โดยผูกกับ 127.0.0.1 และเปิดโหมดเครื่องส่วนตัวที่ไม่ต้องล็อกอิน

ข้อมูลใหม่อยู่ใน JSON ของร่างเดิม ไม่ต้องย้ายฐานข้อมูล และข้อมูลร่างเก่าที่ไม่มีฟิลด์ใหม่จะได้ค่าเริ่มต้นแบบข้อความเดิม

## การตรวจรุ่นนี้

ตรวจ schema และร่างเก่า, เพิ่ม/แทนแม่แบบ, การเก็บและอ่านกลับจากฐานข้อมูลทดสอบ, การ escape ข้อความ, ตารางรายชื่อ 40 คน, TOR ยาวหลายหน้า, บล็อกผู้ลงนาม, PDF จริง ชุดทดสอบใช้ข้อมูลจำลองและฐานข้อมูลแยกจากผู้ใช้

ตัวอย่าง PDF สำหรับตรวจรูปแบบใช้ข้อมูลจำลองทั้งหมด ไม่ใช่รายงานประชุมที่รับรองแล้ว
