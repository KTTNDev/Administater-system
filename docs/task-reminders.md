# กระดิ่งแจ้งเตือนงาน

กระดิ่งอยู่ข้างปุ่มนำทางด้านบนของทุกหน้า ตัวเลขสีแดงคืองานที่ถึงช่วงเตือนและยังไม่รับทราบ ไม่มีเสียงหรือหน้าต่างเปิดแทรกเอง

## เริ่มใช้งาน

1. ใน **งานของฉัน** เพิ่มหรือแก้งาน แล้วระบุ **กำหนดเสร็จ**
2. เปิด **กำหนดเวลาและการแจ้งเตือน** เพื่อเลือกใช้ค่าตั้งต้น วันเตือนล่วงหน้าของงานนี้ หรือวันเตือนเฉพาะ ไม่จำเป็นต้องมีวันครบกำหนดสำหรับการเตือนเฉพาะวัน
3. กดกระดิ่งเพื่อดูรายการ กดชื่องานเพื่อแก้ไข กด **รับทราบ** เพื่อลดตัวเลข หรือ **เตือนอีกครั้งวันที่…** เพื่อพักเตือนถึงวันที่เลือก
4. การเปิดกระดิ่งเฉย ๆ ไม่ล้างสถานะ งานที่รับทราบยังอยู่ในรายการจนเสร็จ เก็บไว้ หรือปิดการแจ้งเตือน

ค่าตั้งต้นเตือนก่อนครบกำหนด 3 วัน 1 วัน วันครบกำหนด และเมื่อเกินกำหนด แต่ละช่วงเป็นการเตือนใหม่ งานที่ทำเสร็จแล้วจะไม่เตือน เปิดงานกลับมาทำใหม่จะเริ่มรอบเตือนใหม่

## กำหนดเวลาเป็นจำนวนวัน

เลือก **นับระยะเวลาจากวันเริ่ม** ใช้วันเริ่มด้านบน เลือกวันปฏิทินหรือวันทำการ และว่าจะรวมวันเริ่มเป็นวันแรกหรือเริ่มวันถัดไป ระบบคำนวณวันครบกำหนดให้

วันทำการข้ามเสาร์–อาทิตย์และวันหยุดเพิ่มเติมที่เจ้าหน้าที่ระบุในตั้งค่ากระดิ่ง ไม่มีฐานวันหยุดราชการอัตโนมัติ ต้องตรวจวันหยุดพิเศษและวิธีนับวันกับระเบียบของงานนั้น

เพิ่มแม่แบบระยะเวลาและแหล่งอ้างอิงได้จาก **ตั้งค่าการแจ้งเตือนงาน** ระบบไม่มีการกำหนดวันตามกฎหมายให้เอง แม่แบบเป็นข้อมูลที่หน่วยงานตรวจสอบและกำหนด การแก้แม่แบบไม่เปลี่ยนงานที่บันทึกไปแล้ว ส่วนวันครบกำหนดเดิมจะคงไว้เมื่อเปิดแก้งาน การปรับวันเริ่มหรือวิธีนับระยะเวลาจะคำนวณใหม่ด้วยรายการวันหยุดปัจจุบัน

## การเก็บข้อมูลและขอบเขต

- การตั้งค่า รับทราบ และเลื่อนเตือนเก็บในฐานข้อมูลเครื่อง รวมอยู่ในชุดสำรองและกู้คืน
- ขณะระบบยังไม่มีบัญชีผู้ใช้แยก สถานะรับทราบและตัวกรองผู้รับผิดชอบใช้ร่วมกันทั้งฐานข้อมูลเครื่องนี้
- ตรวจใหม่ทุกนาที เมื่อกลับมาเปิดหน้าต่าง และเมื่อเปลี่ยนงาน การปิดโปรแกรมไม่ได้ส่งแจ้งเตือนเบื้องหลัง เมื่อเปิดกลับมาจะคำนวณรายการที่ถึงกำหนดอีกครั้ง
- การเลื่อนเตือนไม่เปลี่ยนวันครบกำหนดของงาน

## จุดพัฒนาต่อ

- `src/lib/task-alerts.ts`: ตรวจข้อมูล คำนวณวัน และเลือกช่วงเตือนล่าสุด
- `src/lib/task-alert-db.ts`: ตาราง SQLite `task_alerts` และสถานะต่อรอบกำหนดงาน
- `src/app/task-alert-actions.ts`: ตรวจสิทธิ์ ตรวจข้อมูล และเรียกฐานข้อมูล
- `src/components/task-alert-bell.tsx`: กระดิ่งและรายการเตือน
- `src/components/task-alert-settings.tsx`: ตัวตั้งค่าและแม่แบบ
- `src/components/task-reminder-editor.tsx`: ตัวเลือกในฟอร์มงาน
- `src/app/task-alerts.css`: หน้าตาเฉพาะส่วนนี้ ไม่แก้รูปแบบเอกสาร
