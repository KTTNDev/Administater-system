# พัสดุและครุภัณฑ์ — รุ่น 1.3.0

## ใช้งาน
1. เปิดเมนู พัสดุและครุภัณฑ์ > คลังและรูปภาพ เพิ่มชื่อ รหัส หน่วยนับ ที่เก็บ และรูป PNG/JPEG
2. วัสดุสิ้นเปลืองใช้หนึ่งรหัสต่อชนิด/หน่วยนับ ครุภัณฑ์ลงหนึ่งรหัสต่อชิ้น
3. หน้า เบิก / ยืม เลือก รับเข้าคลัง ใส่จำนวน ราคาต่อหน่วย และหลักฐานรับเข้า บันทึกใบแล้วตรวจสอบก่อนยืนยันรับเข้า
4. ค้นหาหรือใช้เครื่องสแกนบาร์โค้ดที่พิมพ์ข้อความแล้วกด Enter เลือกสินค้าเข้าตะกร้า บันทึกใบเบิก / ใบยืม พิมพ์ให้ผู้เกี่ยวข้องลงชื่อ
5. หลังตรวจหลักฐานอนุมัติและจ่ายของจริง ระบุผู้สั่งจ่าย ตำแหน่ง ผู้จ่าย และเอกสารอ้างอิง แล้วกดยืนยันจ่ายจริง
6. แนบ PDF หรือภาพใบลงนามไว้ที่ใบเดิม ไม่ต้องกรอกรายการใหม่
7. การคืนครุภัณฑ์รุ่นนี้เป็นการคืนครบใบ ตรวจรับจริงก่อนระบุผู้รับคืนและสภาพ
8. ประวัติและรายงานค้นได้จากเลขใบ ชื่อวัสดุ ผู้เบิก หน่วยงาน และเอกสารอ้างอิง กรองวันที่หรือปีงบประมาณ ส่งออก CSV/PDF

## รูปและการจัดเก็บ
ต้นฉบับอยู่ในฐานข้อมูล SQLite ของเครื่อง รวมในสำรอง/กู้คืนของระบบ
อัปโหลดแล้วสร้างสำเนาอ่านได้ใต้พื้นที่จัดเก็บที่ตั้งค่าไว้:
พัสดุและครุภัณฑ์ / รูปประจำรายการ หรือ หลักฐานเบิกจ่าย / รหัสอ้างอิง UUID / รหัสไฟล์.png (.jpg / .pdf)
ไฟล์ละไม่เกิน 8 MB สูงสุด 8 ไฟล์และ 32 MB ต่อรายการ
PNG/JPEG ตรวจด้วยตัวถอดรหัสภาพ ไม่รับ SVG/HTML ปลอมเป็นรูป

เชื่อมต่อ Google Drive ในตั้งค่าระบบเดิม แล้วกด ส่งขึ้น Drive รายไฟล์:
โฟลเดอร์ Drive ที่ตั้งไว้ (หรือ สารบรรณ) / พัสดุและครุภัณฑ์ / ครุภัณฑ์ หรือ วัสดุสำนักงาน หรือ หลักฐานเบิกจ่าย / รหัสรายการ + รหัสอ้างอิง
การส่งซ้ำใช้รหัสไฟล์เดิม ภาพเก็บเป็นต้นฉบับ ไม่แปลงเป็น PDF
การลบไฟล์ในรายการลบข้อมูลที่ใช้งานและสำเนาในโฟลเดอร์จัดเก็บปัจจุบัน สำเนา Drive ชุดสำรองเก่า และสำเนาที่ผู้ใช้ย้ายเองยังอยู่
เมื่อกู้คืนสามารถดู/ดาวน์โหลดภาพจากฐานข้อมูลได้ทันที โฟลเดอร์สำเนาไม่ใช่แหล่งข้อมูลหลัก
การส่งรูปขึ้น Drive ไม่ใช่การสำรองทั้งระบบ ให้ใช้คำสั่งสำรองในตั้งค่าควบคู่กัน

## ขอบเขต
- ใบที่ยังไม่ลงบัญชียกเลิกได้ ต้องระบุเหตุผล เลขใบไม่กลับมาใช้ซ้ำ
- ใบที่ลงบัญชีแล้วไม่ลบหรือแก้ย้อนหลังโดยตรง เก็บประวัติผู้ทำรายการและเวลาระบบ
- ระบบป้องกันจ่ายเกินคงเหลือ และบันทึกทั้งตะกร้าหรือไม่บันทึกเลย
- ยอดรับเข้าสรุปมูลค่าตามราคาที่กรอก ไม่ใช่บัญชีต้นทุน FIFO/เฉลี่ย ค่าเสื่อม หรือทะเบียนบัญชีสินทรัพย์ครบวงจร
- รายงานคงเหลือแสดงยอดปัจจุบัน มีป้ายกำกับชัดเจน ไม่ใช่ยอดย้อนหลังสิ้นงวด
- ชื่อผู้อนุมัติเป็นการบันทึกจากหลักฐานที่เจ้าหน้าที่ตรวจแล้ว ไม่ใช่การยืนยันตัวบุคคลหรือลายเซ็นอิเล็กทรอนิกส์
- การจำหน่าย โอนสินทรัพย์ ตรวจสอบประจำปี และคืนบางส่วนของใบยืมยังใช้ขั้นตอนของหน่วยงาน
- รายการวัสดุแบบเดิมใน งานธุรการ ยังคงอยู่ ไม่ย้ายยอดที่ไม่เคยตรวจรับเข้าคลังใหม่โดยอัตโนมัติ

## หลักเกณฑ์อ้างอิง
ใช้หลักการแยกประเภทและเก็บหลักฐานตามข้อ 203, ผู้เบิกตามข้อ 204, ผู้สั่งจ่าย/ผู้จ่ายและลงบัญชีตามข้อ 205, หลักฐานยืมและกำหนดคืนตามข้อ 208 ของระเบียบกระทรวงการคลังฯ พ.ศ. 2560:
- https://cpb.ddc.moph.go.th/ddc-pic/law/reg-2560/203
- https://cpb.ddc.moph.go.th/ddc-pic/law/reg-2560/204
- https://cpb.ddc.moph.go.th/ddc-pic/law/reg-2560/205
- https://cpb.ddc.moph.go.th/ddc-pic/law/reg-2560/208

แบบพิมพ์ของระบบเป็นแบบใช้งานประกอบหลักฐาน ให้หน่วยงานตรวจอำนาจผู้ลงนามและรายละเอียดเฉพาะของตนก่อนใช้ ไม่อ้างว่าแทนแบบทะเบียนบัญชีทุกประเภทตามระเบียบ

## แบบฟอร์มและรายงาน รุ่น 1.4.0
เข้า **คลังพัสดุและครุภัณฑ์ → แบบฟอร์มและผลตรวจ** เลือกแบบและวันที่ แล้วเชื่อมวัสดุ ครุภัณฑ์ หรือใบเบิกตามประเภท

แบบที่รองรับ: บัญชีวัสดุ, ทะเบียนคุมทรัพย์สิน, ทะเบียนครุภัณฑ์ต่ำกว่าเกณฑ์, ใบเบิกพัสดุ, รายการวัสดุคงเหลือ, รายงานสินทรัพย์คงเหลือ, รายงานพัสดุชำรุด/ไม่จำเป็นต้องใช้, บันทึกข้อความตรวจสอบพัสดุประจำปี

1. กรอกข้อมูลเอกสาร แก้รายการตาราง และระบุผู้ลงนามจากบนลงล่าง
2. เพิ่ม ลบ หรือเลื่อนลำดับแถวได้ รายการจำนวนมากพับเก็บได้
3. ดูตัวอย่างข้างฟอร์ม ปรับขนาดตัวอย่างได้ ตารางยาวแบ่งหน้าและพิมพ์หัวตารางซ้ำ
4. บันทึกร่างก่อนส่งออก PDF หรือ Word ทุกแบบใช้ TH Sarabun New; Word เป็นข้อความและตารางที่แก้ไขต่อได้
5. เปิดร่างเดิมจากรายการด้านล่างหรือค้นหาชื่อ ร่างรวมอยู่ในชุดสำรองและกู้คืนของระบบ

ไฟล์อ้างอิงทั้ง 8 แบบจาก https://drive.google.com/drive/folders/1hvQjmfb6aW4srAJ-8-Sc3BgNsN25FGhv ใช้กำหนดหัวข้อและข้อมูล ไม่คัดลอกขนาดฟอนต์/ตำแหน่งเซลล์ Excel ตามคำขอที่ปรับล่าสุด

- ยอดในบัญชีวัสดุ/รายการคงเหลือคำนวณจากรายการที่ลงบัญชีถึงวันที่เลือก ครุภัณฑ์ที่ให้ยืมยังนับเป็นทรัพย์สินของหน่วยงาน
- แก้ไขร่างแล้วไม่ตัดสต็อกซ้ำ ผู้ใช้ยังลงบัญชีผ่านขั้นตอนรับเข้า/เบิกจ่ายเดิม
- ราคาคงเหลือ ค่าเสื่อม แหล่งเงิน ผลตรวจสภาพ และผลตรวจประจำปี ให้กรอกจากหลักฐานจริง ระบบไม่ถือว่าตรวจนับหรืออนุมัติแล้ว
- วัสดุคงเหลือคำนวณจำนวนเงินหลังใส่ราคา หากราคาไม่ครบ จะไม่แสดงยอดรวมเสมือนครบถ้วน
- รองรับไม่เกิน 500 แถวต่อร่าง แถวเดี่ยวที่สูงเกินหน้าจะเตือนและระงับส่งออก PDF/Word ให้ย่อข้อมูลก่อน

### การวิเคราะห์
เข้าที่แท็บ **วิเคราะห์พัสดุ** หรือหน้า **รายงาน → วิเคราะห์พัสดุและครุภัณฑ์** เลือกปีงบประมาณหรือช่วงวันที่ แล้วส่งออก PDF สำหรับนำเสนอ หรือ CSV สำหรับวิเคราะห์ต่อ

รับเข้า/เบิกจ่ายใช้ช่วงวันที่ที่เลือก ตัดปลายช่วงไว้ที่วันปัจจุบันถ้าเลือกปีงบประมาณที่ยังไม่สิ้นสุด ส่วนสต็อกและใบยืมค้างแสดงสถานะปัจจุบัน มีวันที่กำกับ ค่าเฉลี่ยพอใช้คำนวณรายวัสดุ ไม่รวมจำนวนต่างหน่วยเข้าด้วยกัน และยังไม่รวมระยะเวลาจัดซื้อหรือฤดูกาล มูลค่ารับเข้าไม่ใช่มูลค่าทรัพย์สินสุทธิ
