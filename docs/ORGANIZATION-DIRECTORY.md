# จัดการรายชื่อหน่วยงาน — รุ่น 1.2.3

## เพิ่ม แก้ไข หรือลบ

- ไปที่ **ตั้งค่าหน่วยงานและ Drive → รายการกรอกอัตโนมัติ**
- กด **เพิ่มหน่วยงาน** กรอกชื่อส่วนราชการ หน่วยงานเจ้าของเรื่อง ที่อยู่ โทรศัพท์ และรหัสหน่วยงาน แล้วบันทึก
- ค้นจากชื่อ กอง ที่อยู่ โทรศัพท์ หรือรหัส แล้วกดแก้ไขหรือลบ ระบบถามยืนยันก่อนลบ
- รายชื่อที่มีชื่อส่วนราชการและหน่วยงานเจ้าของเรื่องเหมือนกันจะไม่ถูกเพิ่มซ้ำ
- หากอีกหน้าต่างแก้ไขรายการเดียวกัน ระบบไม่ให้บันทึกข้อมูลเก่าทับ ให้โหลดรายชื่อล่าสุดก่อน

## ใช้ระหว่างทำหนังสือ

กด **จัดการรายชื่อหน่วยงาน** ข้างช่องกรอกข้อมูลหน่วยงานอัตโนมัติได้เลย หน้าต่างจัดการเปิดทับฟอร์มเดิม การปิดหน้าต่างจะกลับไปยังร่างที่กรอกค้างไว้ เมื่อบันทึกรายชื่อแล้วจะเลือกใช้ได้ทันที

เมื่อเลือกหน่วยงาน ระบบคัดลอกชื่อ หน่วยงานเจ้าของเรื่อง ที่อยู่ และโทรศัพท์ลงฟอร์ม ช่องเหล่านี้ยังแก้เองได้ การแก้หรือลบรายชื่อภายหลังไม่เปลี่ยนหนังสือที่เคยกรอกไว้ และไม่ออกเลขหนังสือให้อัตโนมัติ

## หน่วยงานหลักและข้อมูลเดิม

หน่วยงานหลักด้านบนของหน้าตั้งค่าเป็นค่าเริ่มต้นสำหรับการสร้างร่างใหม่ ส่วนรายการกรอกอัตโนมัติเป็นสมุดรายชื่อสำหรับเลือกใช้กับฟอร์ม ทั้งสองส่วนตั้งค่าแยกกัน

เมื่อเปิดรุ่นนี้ครั้งแรก ระบบนำหน่วยงานหลักเดิมและรายการตัวอย่างเดิมมาเป็นรายชื่อที่แก้ไขได้ ลบรายการตัวอย่างที่ไม่ใช้ได้ และรายการที่ลบแล้วจะไม่กลับมาเอง

รายชื่อรวมในสำรองข้อมูลอัตโนมัติ/ด้วยตนเองและการย้ายเครื่อง ใช้รุ่น 1.2.3 หรือใหม่กว่าเพื่อกู้ชุดสำรองที่มีตารางรายชื่อหน่วยงาน รุ่นเก่าจะไม่รับตารางที่ยังไม่รองรับ
