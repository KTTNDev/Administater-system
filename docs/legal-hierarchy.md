# คลังกฎหมายแบบเอกสารหลักและเอกสารต่อเนื่อง

## การใช้งาน

1. เพิ่มระเบียบตั้งต้นด้วยปุ่ม **เพิ่มเอกสาร** และเลือก “ไม่มี — เป็นเอกสารตั้งต้น”
2. ที่ระเบียบนั้น กด **เพิ่มเอกสารต่อเนื่อง** เพื่อเพิ่มประกาศ ฉบับแก้ไข หรือหนังสือซักซ้อม
3. เลือกความสัมพันธ์กับต้นทาง แนบ PDF หรือลิงก์และโน้ต แล้วบันทึก
4. กด **เอกสารต่อเนื่อง … ฉบับ** เพื่อเปิด/พับกลุ่ม สามารถเพิ่มลูกใต้ลูกต่อได้
5. เอกสารเดิมใช้ **แก้ไข → อยู่ภายใต้เอกสาร** เพื่อจัดเข้ากลุ่มหรือย้ายทั้งสาย
   เลือก “ไม่มี” เมื่อต้องการแยกเป็นฉบับตั้งต้น

การค้นหาจะแสดงฉบับที่พบพร้อมต้นทางและเอกสารต่อเนื่องของฉบับนั้น เพื่อรักษาบริบท
การเลือกสถานะใช้เฉพาะข้อมูลที่เจ้าหน้าที่ตรวจบันทึกเอง การจัดกลุ่มไม่เปลี่ยนสถานะ
ใช้บังคับ/ยกเลิกของเอกสารโดยอัตโนมัติ ทุกฉบับยังมีไฟล์ โน้ต และสถานะแยกกัน

## ข้อมูลและการแก้ไขโค้ด

- `src/lib/legal.ts`: เพิ่ม `parentId` และ `relationship` ใน JSON เดิม; ค่าเริ่มต้น
  ทำให้ข้อมูลเก่าเป็นฉบับตั้งต้นโดยไม่เปลี่ยนหรือลบแถวข้อมูล
- `src/app/legal-actions.ts`: ตรวจว่าต้นทางมีอยู่และไม่เชื่อมวนใน transaction เดียวกับ
  การบันทึก ป้องกันการลบฉบับที่มีลูก และยังตรวจการอ้างอิงในร่างหนังสือเหมือนเดิม
- `src/components/legal-tree.tsx`: กลุ่มพับเปิดได้ ค้นหาพร้อมบริบท และปุ่มต่อเอกสาร
- `src/components/legal-parent-fields.tsx`: ฟอร์มเลือกต้นทางร่วมกันทั้งหน้าคลังและ
  คลังในหน้าร่างหนังสือ ไม่ให้เลือกตัวเองหรือเอกสารลูกเป็นต้นทาง
- `src/components/law-library.tsx`: จัดการฟอร์ม/อ่าน PDF/เปรียบเทียบ/อัปโหลดเดิม
- `src/components/document-tools.tsx`: แสดงสายต้นทางเมื่อต้องเลือกกฎหมายในร่างหนังสือ

ไม่เปลี่ยนตัวสร้างเนื้อหาเอกสารหรือรูปแบบพิมพ์ เอกสารต่อเนื่องแต่ละฉบับยังใช้ ID เดิม
เมื่อย้ายกลุ่ม การสำรองฐานข้อมูลเดิมรวมโครงสร้างและ PDF ด้วย เพราะเก็บในตาราง
`legal_library` เดิม การอัปโหลด PDF แยกฉบับไป Drive ยังใช้โฟลเดอร์หมวดหมู่/ปีเดิม
หากต้องการย้ายโครงสร้างทั้งคลัง ให้ใช้การสำรองและกู้คืนฐานข้อมูลของระบบ
