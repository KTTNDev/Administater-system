# ติดตามความคืบหน้างานของฉัน

เปิด **งานของฉัน** เพื่อดูภาพรวม งานค้าง กำหนดส่ง และเปอร์เซ็นต์ของแต่ละงาน กดชื่องานเพื่อแก้ไข หรือกดเพิ่มงานใหม่

## วิธีติดตาม

- **กำหนดเปอร์เซ็นต์เอง**: ใส่ค่าประเมิน 0–100 พร้อมขั้นตอนถัดไป เช่น “ตรวจข้อมูลที่ได้รับ”
- **คำนวณจากรายการย่อย**: เพิ่มขั้นตอนสูงสุด 50 รายการ เช็กสิ่งที่ทำเสร็จ เปอร์เซ็นต์คำนวณจากจำนวนที่เสร็จเทียบทั้งหมด โดยให้น้ำหนักเท่ากัน ปิดงานไม่ได้หากรายการย่อยยังไม่ครบ
- เมื่อเช็กครบทุกข้อ เปอร์เซ็นต์จะเป็น 100% แต่ยังเลือกสถานะรอผล/กำลังทำต่อได้ จนกว่าเจ้าของงานจะยืนยันสถานะ **เสร็จสิ้น** เช่น กรณีรอการรับรองผลงาน
- งานที่กำหนดเปอร์เซ็นต์เองจะแสดง 100% เมื่อปิดงาน หากเปิดกลับมาดำเนินการ ระบบยังเก็บเปอร์เซ็นต์ที่ประเมินไว้ก่อนปิด จึงปรับต่อได้
- สถานะยังไม่เริ่มจะเปลี่ยนเป็นกำลังทำเมื่อมีความคืบหน้ามากกว่า 0 ไม่คาดเดาเปอร์เซ็นต์จากชื่อสถานะ
- งานรอผลมีช่องบันทึกสิ่งที่กำลังรอหรือปัญหาที่ติดอยู่ แสดงในรายการให้เห็นโดยไม่ต้องเปิดรายละเอียดทุกครั้ง

## ค้นหาและดูภาพรวม

เลือกชื่อใน **กรองผู้รับผิดชอบงาน** เพื่อดูงานของตนเอง ค้นได้จากชื่อ รายละเอียด รายการย่อย ขั้นตอนถัดไป และสิ่งที่รอ ปุ่มสรุปสถานะใช้เปลี่ยนตัวกรอง รายการเฉลี่ยด้านบนคำนวณจากงานทุกสถานะของผู้รับผิดชอบที่เลือก ไม่รวมงานที่เก็บไว้ ไม่เกี่ยวข้อง และงานในโครงการที่พักไว้ ตัวกรองนี้ช่วยจัดมุมมอง ไม่ใช่ระบบกำหนดสิทธิ์การเข้าถึง

กด **ส่งออกงาน CSV** เพื่อส่งออกเฉพาะรายการที่ตรงกับตัวกรองปัจจุบัน รวมเปอร์เซ็นต์ จำนวนรายการย่อย ขั้นตอนถัดไปและสิ่งที่รอ ใช้เปิดใน Excel ได้

## การจัดเก็บ

ใช้รายการงานเดิมในตาราง `office_items` ของ SQLite ไม่สร้างฐานข้อมูลอีกชุด ข้อมูลติดตามจึงรวมในสำรองอัตโนมัติ/ด้วยมือและชุดสำรองที่ซิงก์ Drive ตามการตั้งค่าระบบ งานเก่ายังเปิดได้ด้วยค่าเริ่มต้น และป้องกันการบันทึกทับข้อมูลจากหน้าต่างที่ถือเวอร์ชันเก่า

การสร้างงานปีถัดไปเก็บชื่อรายการย่อยเป็นต้นแบบ แต่ล้างเครื่องหมายเสร็จ เปอร์เซ็นต์ สิ่งที่รอ และขั้นตอนถัดไป เพื่อไม่ให้ดูเหมือนงานปีใหม่ทำเสร็จแล้ว
