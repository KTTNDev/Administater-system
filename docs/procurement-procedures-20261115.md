# กระบวนงานหนึ่งเรื่องและทะเบียนหลักเกณฑ์จัดซื้อจัดจ้าง

ตรวจค้นวันที่ 15 พฤศจิกายน 2569 สำหรับออกแบบระบบ ยังไม่ใช่การรับรองว่าได้รวบรวมข้อยกเว้นเฉพาะพัสดุทุกประเภทครบถ้วน

## หลักการที่ผู้ใช้ยืนยัน

เข้าหมวดจัดซื้อจัดจ้าง → เลือกจัดซื้อหรือจัดจ้าง → เลือกแนวทางที่เข้าเงื่อนไข → เพิ่มงานหนึ่งเรื่อง → กรอกข้อมูลหลักของบิล/ใบเสนอราคาครั้งนั้นเพียงครั้งเดียว → สร้างเอกสารครบชุดที่ใช้กับแนวทางนั้น → เปิดแก้แต่ละฉบับได้ โดยรักษาแม่แบบต้นฉบับที่ผู้ใช้ยอมรับ

ผู้ใช้ยืนยันให้เปลี่ยนตัวอักษรสีแดงที่ใช้เตือนตนเองเป็น **สีดำในฉบับใช้งาน** เก็บไฟล์อ้างอิงเดิมไว้ได้ การเปลี่ยนสีนี้เป็นความต่างที่ผู้ใช้อนุญาต ไม่ถือเป็นความผิดพลาดในการรักษาต้นฉบับ

หนึ่งงานมีข้อมูลกลางและชุดเอกสาร ไม่ใช่สร้างเอกสาร D07 ทีละฉบับแล้วให้พิมพ์ข้อมูลซ้ำ งานหนึ่งอาจมีใบเสนอราคา/บิลหลายไฟล์ ผู้ค้าคนเดียวมีหลายงานได้ วงเงินที่ใช้พิจารณาต้องเป็นวงเงินการจัดซื้อจัดจ้างครั้งนั้น ไม่ใช้ยอดต่อแผ่นของบิลแทนวงเงินทั้งงานอัตโนมัติ

## สิ่งที่ต้องแยกในระบบ

1. ประเภทงาน: จัดซื้อ / จัดจ้าง และชนิดย่อย เช่น วัสดุ ครุภัณฑ์ บริการ ซ่อมแซม ก่อสร้าง ที่ปรึกษา ออกแบบ/ควบคุมงาน
2. วิธีจัดซื้อจัดจ้าง: ประกาศเชิญชวนทั่วไป / คัดเลือก / เฉพาะเจาะจง พร้อมฐานอำนาจที่เลือก
3. แนวปฏิบัติ/ข้อยกเว้น: เช่น ว119 ตาราง 1, ว119 ตาราง 2, ว804 หรือกระบวนการปกติ ต้องเก็บรายการและเงื่อนไขที่เข้าได้
4. หน้าที่ใน e-GP: บันทึก / เข้าเงื่อนไขยกเว้น / รอตรวจเงื่อนไข ไม่สร้างเป็นวิธีจัดซื้อชื่อ “ว322” แล้วถือว่าเสร็จแทนวิธีตามกฎหมาย
5. ชนิดหลักฐานและช่วงงานจริง: ใบเสนอราคา ใบส่งของ ใบแจ้งหนี้ ใบเสร็จ/ใบกำกับภาษีเป็นคนละชนิด การได้รับใบเสร็จไม่ทำให้ระบบสร้างข้อเท็จจริงว่าได้รับอนุมัติไว้ก่อนแล้ว

## หน้ากรอกข้อมูลหลักและการสร้างเอกสาร

ข้อมูลกลางประกอบด้วยชื่องาน ซื้อ/จ้าง/ชนิดย่อย หน่วยงานและปีงบประมาณ วัตถุประสงค์ แนวปฏิบัติและรายการที่เข้าเงื่อนไข คู่ค้า/ข้อเสนอ รายการจำนวนหน่วยราคาภาษี เลขและวันที่หลักฐาน งบประมาณ ผู้รับผิดชอบ/ผู้ลงนาม และกำหนดส่งมอบ/สัญญา ข้อมูลยังไม่ทราบเก็บเป็นยังไม่ครบ ไม่เดาวันอนุมัติ เลขจากระบบภายนอก หรือผลตรวจรับ

เมื่อสร้างชุดเอกสาร ให้เก็บ `caseId + caseRevision + templateId + templateVersion + procedureVersion` ของทุกฉบับ และตรวจว่าข้อมูลจำเป็นครบตามขั้นตอน เอกสารที่ยังไม่ถึงขั้นสร้างร่างรอได้โดยไม่ถือว่าได้รับอนุมัติหรือครบหลักฐานแล้ว รายการที่เลือกไฟล์e-GP/e-LAASแต่ยังไม่แนบให้แสดงรอต้นฉบับ

แต่ละฉบับประกอบจาก snapshot ข้อมูลกลางกับค่าที่แก้เฉพาะฉบับ ผู้ใช้แก้ทุกส่วนได้ตามที่ยืนยัน การแก้เฉพาะฉบับไม่ย้อนทับข้อมูลกลางหรือฉบับอื่นเงียบ ๆ เมื่อต้องการเปลี่ยนข้อมูลกลาง ระบบแสดงฉบับที่ได้รับผลให้เลือกอัปเดต ส่วนที่ลงนาม/ส่งคลังแล้วเก็บคงเดิมและออกเป็นรุ่นใหม่ตามเหตุผล

ชุดเอกสารเป็น checklist ตามแนวทาง ไม่บังคับทุกหมวดมี14ฉบับเท่ากัน โดยเฉพาะว119/ว804ที่ชุดและลำดับต่างจากกระบวนการปกติ ใช้แม่แบบต้นฉบับที่ตรวจแล้วกับแต่ละชนิด เอกสารD05–D11ยังเลือกไฟล์ภายนอกหรือร่างเองจากข้อมูลระบบตามข้อกำหนดเดิม และเอกสารฎีกาจริงยังรับจากe-LAAS

ปิดกระบวนงานเจ้าของเรื่องเมื่อคลังลงรับรอบสอง ตามข้อกำหนดเดิม กำหนดสัญญาและภาระผูกพันยังติดตามแยกต่างหาก

## สถานะการพัฒนา

ปัจจุบันมีตัวแก้D07ตามต้นฉบับและฉบับใช้งานสีดำ ส่วนหน้าสร้างงานระดับเรื่อง/เลือกแนวทางและการสร้างครบชุดจากข้อมูลครั้งเดียวยังต้องพัฒนาต่อ เอกสารนี้บันทึกความเข้าใจและเกณฑ์ลงมือ ไม่ใช่การอ้างว่าหน้าดังกล่าวพร้อมใช้แล้ว ลำดับงานคือเชื่อมข้อมูลกลางและแม่แบบที่เหลือพร้อมการแก้เฉพาะฉบับ โดยรักษาเกณฑ์ความเหมือนเดิมและตรวจใบต่อ/ข้อความยาวควบคู่กัน
