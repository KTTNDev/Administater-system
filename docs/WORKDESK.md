# โต๊ะทำงาน งานประจำ และโครงการรายปี
ปรับปรุง 1 พฤศจิกายน 2569

หน้า Home ใช้ชื่อ sarabun และข้อความพิมพ์วนเฉพาะความสามารถจริง มีปุ่มหยุดและรองรับการลดการเคลื่อนไหว หน้าเอกสารไม่ใช้เอฟเฟกต์นี้

## เริ่มใช้งาน
เปิด http://localhost:3000/home หรือเมนู **โต๊ะทำงานวันนี้**
- วันนี้: เวลา งานครบกำหนด งานเกินกำหนด งานที่ปิดวันนี้ และโครงการของปีงบประมาณปัจจุบัน
- งานของฉัน: พิมพ์ชื่องานแล้ว Enter เพื่อเพิ่มอย่างรวดเร็ว กดชื่องานเพื่อแก้ผู้รับผิดชอบ วันเริ่ม กำหนดส่ง รายละเอียด และหนังสือที่เกี่ยวข้อง
- โครงการประจำปี: เลือกปีงบประมาณ ค้นชื่อหรือผู้รับผิดชอบ กรองตามเดือน และเลือกโครงการเพื่อดูงานย่อย

เช็กช่องเมื่องานเสร็จ กด **เลิกทำ** เพื่อย้อนสถานะล่าสุด
ปุ่มเก็บงาน/พักโครงการไม่ลบข้อมูล เปิดดูรายการที่เก็บไว้แล้วนำกลับได้
การเปลี่ยนหน้าขณะพิมพ์ข้อมูลที่ยังไม่บันทึกจะขอให้ยืนยันก่อน

## เริ่มเรียนรู้งานกองสวัสดิการสังคม
ยังไม่สร้างโครงการจริงให้อัตโนมัติ เพราะต้องยืนยันแผนและขอบเขตงานกับหน่วยงานก่อน
มีชุดตัวอย่างให้เลือกตรวจและแก้ชื่อก่อนบันทึก:
1. กิจกรรมส่งเสริมคุณภาพชีวิตผู้สูงอายุ
2. กิจกรรมส่งเสริมอาชีพชุมชน
3. เตรียมแผนงานประจำปีของกอง

แต่ละชุดมีงานย่อย 6 รายการเพื่อเริ่มวางแผน แก้ไข เพิ่ม หรือนำออกจากรายการได้
ตัวอย่างเหล่านี้ไม่ใช่รายการงานที่กฎหมายกำหนดหรือแผนอนุมัติของกอง

## ปีงบประมาณและความคืบหน้า
ปีงบประมาณเริ่ม 1 ตุลาคม ถึง 30 กันยายน เช่น 2570 คือ 1 ต.ค. 2569–30 ก.ย. 2570
เปอร์เซ็นต์ = งานย่อยที่ทำเสร็จ / งานย่อยที่ยังอยู่ในโครงการ
ไม่ใช่เปอร์เซ็นต์เบิกจ่ายหรือผลอนุมัติ ต้องปิดสถานะโครงการเองเมื่อเหมาะสม
ระบบไม่ให้ปิดโครงการหากยังมีงานย่อยไม่เสร็จ
แก้ปีของโครงการแล้ว งานย่อยจะตามปีโครงการ แต่วันที่ที่กรอกไว้ไม่เปลี่ยนเอง

เลือก **เป็นงานประจำปี** แล้วกด **สร้างปีถัดไป**:
- สร้างสำเนางาน/โครงการและงานย่อยที่ยังใช้งาน
- เริ่มสถานะใหม่ เลื่อนวันตามปี และไม่คัดลอกเลขหรือการเชื่อมหนังสือเดิม
- กดซ้ำจะเปิดชุดปีถัดไปเดิม ไม่สร้างซ้ำ
- ตรวจวันจริงและงบประมาณก่อนใช้ในปีใหม่

ส่งออก CSV ได้ทั้งโครงการและงานของปีที่เลือก รวมรายการที่พักไว้โดยมีคอลัมน์บอกสถานะ
เปิดใน Excel ได้ ภาษาไทยมี UTF-8 BOM และป้องกันข้อความถูกตีความเป็นสูตร

## ข้อมูลและการย้ายเครื่อง
บันทึกลงฐานข้อมูลเดียวกับระบบเดิม ตาราง office_items และ audit
ใช้เมนูสำรองข้อมูลเดิมได้ งานและโครงการรวมอยู่ในชุดสำรองแล้ว
ค่าปริยายฐานข้อมูลคือ data/sarabun.sqlite แต่ให้ตรวจ DATABASE_PATH ใน .env.local ของเครื่องนั้น
อย่าใช้ GitHub แทนการสำรองข้อมูลจริง เพราะฐานข้อมูลและไฟล์ตั้งค่าส่วนตัวไม่ถูกส่งขึ้น Git

## สำหรับผู้พัฒนาต่อ
- src/components/capability-typewriter.tsx: ข้อความพิมพ์วน แบ่งกลุ่มอักขระไทย และหยุดเมื่อซ่อนหน้าต่าง
- src/components/workdesk.tsx: หน้าจอ งานด่วน กล่องแก้ไข และการนำทาง
- src/app/workdesk.css: รูปแบบที่จำกัดอยู่กับหน้าโต๊ะทำงาน ไม่แก้สไตล์กระดาษ
- src/lib/workdesk.ts: ปีงบประมาณ การคัดลอกงานรายปี การคำนวณความคืบหน้า และชุดตัวอย่าง
- src/lib/office.ts: โครงสร้างข้อมูลและค่าเริ่มต้นสำหรับข้อมูลเก่า
- src/lib/office-db.ts: ตรวจเงื่อนไข บันทึกแบบ transaction ตรวจ version กันการเขียนทับ และประวัติการแก้ไข
- src/app/office-actions.ts: ตรวจผู้ใช้ก่อนอ่าน/เขียนข้อมูลบนเซิร์ฟเวอร์
- src/app/home/page.tsx: ใช้ตัวโหลดข้อมูลและสิทธิ์ของ workspace เดิม
- src/app/welcome/page.tsx: หน้าต้อนรับและภาพพื้นหลังเดิม
- tests/workdesk.test.ts: เงื่อนไขข้อมูลและปีงบประมาณ
- tests/e2e/workdesk.spec.ts: การใช้หน้าจอจริงกับฐานข้อมูลทดสอบ

ลำดับการทำงาน: หน้า UI → server action → ตรวจข้อมูล/สิทธิ์/version → transaction → ส่งรายการล่าสุดกลับ UI
การแก้เนื้อหาหรือการพิมพ์เอกสารยังใช้ระบบเอกสารเดิม
