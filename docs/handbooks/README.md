## สร้างเล่มใหม่

จากราก repo หลัง `npm ci` และมี Chrome/Edge:

```powershell
node scripts/build-developer-handbook.mjs
```

ผล PDF และ HTML อยู่ `output/pdf/` ฟอนต์ไทยฝังในไฟล์ อ่านได้โดยไม่ต้องติดตั้งฟอนต์เพิ่ม ตัวสร้างตรวจ content overflow ทุกหน้าและเก็บภาพตรวจใน `tmp/pdfs/developer-handbook/` ควรตรวจ PDF จริงซ้ำก่อนแทนที่ไฟล์ในโฟลเดอร์นี้

เมื่อทำคู่มือรุ่นใหม่ ให้ปรับ version/commit ในตัวสร้างและทวนทุกบทตามซอร์สใหม่ หากเพิ่มจำนวนบทเกิน 44 ต้องปรับการแบ่งสารบัญสองหน้าของตัวสร้างด้วย
