# ขอบเขตเมนู TOR วัสดุ — การสำรวจเบื้องต้น

แหล่งอ้างอิง: https://tor-material.peeraphacharaphorn.workers.dev/

ตรวจเมื่อ 5 พฤศจิกายน 2569 จากโครงสร้าง HTML ที่หน้าเว็บเผยแพร่ก่อนล็อกอิน ยังไม่ได้ตรวจผลลัพธ์เอกสารหรือสิทธิ์หลังล็อกอิน ผู้ใช้แจ้งว่าเข้าได้แล้วในเบราว์เซอร์ของตน แต่เซสชันเบราว์เซอร์ทดสอบของผู้ช่วยปิดแล้ว และเครื่องมือปัจจุบันยังอ่านแท็บที่ผู้ใช้ล็อกอินไม่ได้

## ฟังก์ชันที่พบในโครงสร้างหน้าสาธารณะ

- ค้นหาวัสดุตามชื่อ/รหัส กรองหมวด เลือกหลายรายการ ระบุจำนวนและราคาต่อหน่วย
- TOR แบบลดรูป 5 หัวข้อ และแบบเต็ม 11 หัวข้อ
- ชื่อเรื่อง วิธีจัดซื้อ ระยะเวลา/สถานที่ส่งมอบ ระยะเวลายืนราคา และข้อกำหนดเพิ่มเติม
- ความเป็นมา วัตถุประสงค์ ปีงบประมาณ แหล่งเงิน ค่าปรับ และการรับประกัน
- เพิ่มกรรมการ และมีข้อความระบุว่าจำรายชื่อไว้ใช้ครั้งถัดไป
- เลือกเลขไทย ส่งออก Word และพิมพ์ TOR
- ประวัติการพิมพ์ของหน่วยงาน รายการวัสดุที่พิมพ์มาก และการพิมพ์ล่าสุด
- ข้อมูลหน่วยงาน ผู้ติดต่อ และโลโก้
- มีโครงสร้างหน้าจัดการวัสดุ นำเข้า JSON ส่งออกข้อมูล จัดการหัวข้อแม่แบบ และคืนค่าเริ่มต้น
- มีส่วนบริหารหน่วยงานสมาชิกและการอนุมัติการลงทะเบียน ซึ่งอาจจำกัดสิทธิ์ผู้ดูแล ต้องตรวจบทบาทก่อนนำมาปรับใช้

## การเชื่อมกับ sarabun

ใช้เมนู TOR วัสดุเป็นงานใหม่ เชื่อมข้อมูลหน่วยงานที่มีอยู่และรายการวัสดุที่ผู้ใช้เลือกได้ ให้จัดเก็บร่างใน SQLite รวมการสำรองและกู้คืนตามระบบเดิม ใช้ฟอนต์และการแสดงตัวอย่างเอกสารของ sarabun พร้อมแก้ไขก่อนส่งออก Word/PDF

การจัดทำ TOR เป็นขั้นตอนเตรียมเอกสาร จึงยังไม่เปลี่ยนยอดสต็อกของระบบเบิกจ่าย ค่าปรับ วิธีจัดซื้อ และเงื่อนไขสัญญาต้องให้ผู้ใช้ตรวจสอบตามงาน ไม่อนุมานค่าเริ่มต้นทางกฎหมายจากชื่อฟิลด์

## ยังต้องตรวจจากการใช้งานจริง

1. เมนูที่บัญชีผู้ใช้เข้าถึงได้จริง เทียบกับเมนูผู้ดูแล
2. ลำดับการเลือกวัสดุ แก้คุณลักษณะ และเติมรายละเอียด
3. ชื่อและเนื้อหาหัวข้อของ TOR ทั้งสองแบบ รวมเงื่อนไขที่ซ่อน/แสดง
4. รูปแบบ Word และการพิมพ์: ตาราง ยอดรวม ลายเซ็น การแบ่งหน้า
5. ประวัติสามารถเปิดแก้ คัดลอก หรือส่งออกซ้ำได้หรือไม่
6. รูปแบบไฟล์นำเข้า/ส่งออก และสิทธิ์ในรายการวัสดุของแต่ละหน่วยงาน

ยังไม่มีการเพิ่มเมนูหรือเปลี่ยนระบบเอกสารจากข้อมูลสำรวจนี้
