## สีและไฟล์ที่เกี่ยวข้อง

| หมวด | สี | หน้าที่ใช้ร่วมกัน |
| --- | --- | --- |
| หนังสือ | ฟ้า | เอกสารของฉัน แบบหนังสือ เขียนหนังสือ ทะเบียนรับ–ส่ง |
| งานประจำ | พีช | To-do และงานธุรการ |
| โครงการ | เขียว | โครงการประจำปีและรูปเล่ม |
| พัสดุ | ทราย / เหลืองอ่อน | พัสดุ ครุภัณฑ์ และการเบิก |
| รายงาน | ม่วงอ่อน | ภาพรวม รายงาน และงบประมาณ |
| ตารางเวลา | เขียวอมฟ้า | ปฏิทินและห้องประชุม |
| อ้างอิง | เทาอุ่น | กฎหมาย คู่มือ ตั้งค่า |

สีอยู่ใน `src/app/workspace-craft.css` และการจับคู่หน้าอยู่ใน `src/lib/workspace-theme.ts`
เมนูและการ์ดใช้ `data-workspace-category` ส่วนหัวหน้าใช้ `function-banner`
เปลี่ยนสีที่ token เดียวเพื่อให้ทุกตำแหน่งตรงกัน ไม่ใช้สีหมวดแทนสีแจ้งเตือนหรือสถานะงาน

## กลับหน้าตาก่อนปรับ

เรียกเวอร์ชันก่อนปรับนี้ว่า **ก่อน Craft — df7e78c** (มีระบบรูปเล่มโครงการแล้ว)
หากต้องการย้อน ให้ระบุว่า “กลับหน้าตาก่อน Craft” และย้อนเฉพาะ commit ของงาน UI นี้
ด้วย `git revert <commit ของ Craft UI>` หลังตรวจ working tree และสำรองงานที่ยังไม่ commit
จากนั้นสร้างโปรแกรมและเปิดใหม่:

```powershell
& ./.desktop/runtime/node.exe scripts/build-desktop.mjs
& ./.desktop/runtime/node.exe scripts/desktop.mjs stop
& ./.desktop/runtime/node.exe scripts/desktop.mjs start --no-browser
```

การย้อนเฉพาะโค้ดไม่ต้องกู้ฐานข้อมูลทับข้อมูลปัจจุบัน ไม่ใช้ `reset --hard` เพื่อย้อนหน้าตา
