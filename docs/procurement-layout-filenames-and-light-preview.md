# รูปแบบบันทึกข้อความ ชื่อไฟล์ และการลดภาระตัวอย่าง

ปรับปรุง 16 พฤศจิกายน 2569

## รูปแบบเอกสาร

บันทึกข้อความในชุดจัดซื้อจัดจ้างทั้ง 8 แบบใช้เส้นใต้แบบจุดต่อถึงขอบขวาของพื้นที่ข้อความ เมื่อส่วนราชการสั้นเส้นจึงไม่หยุดตามความยาวตัวอักษร ลบแท็บปลายบรรทัดเดิมก่อนเพิ่มแท็บใหม่เพื่อไม่ให้เกิดบรรทัดว่าง

ชื่อและตำแหน่งผู้ลงนามใช้พื้นที่และจุดกึ่งกลางเดียวกัน แทนแท็บชิดซ้ายคนละระยะ โดยรักษาฟอนต์เดิม ภาพตราครุฑ และพิกัดกล่องความเห็นแบบเรียงเยื้องตามสายเสนอ กล่องความเห็นที่ลอยอยู่ท้ายบันทึกมีการกันพื้นที่สำหรับแบ่งหน้า เพื่อไม่ให้ถูกตัดขอบกระดาษ หากพื้นที่ไม่พอจะขึ้นหน้าต่อพร้อมคำต่อหน้าและหมายเหตุใบต่อ

ไฟล์ต้นฉบับที่ตรวจ SHA-256 และไฟล์หลักฐานที่เคยแนบยังคงเดิม การปรับรูปแบบใช้เมื่อสร้างจากข้อมูลของงานฉบับใหม่ เอกสารเก่าจะแสดงข้อความให้สร้างใหม่เมื่อรุ่นแม่แบบเปลี่ยน ชุดส่งคลังที่ตรึงไว้ยังอ้างอิงไฟล์และ hash เดิม

## ชื่อไฟล์

รูปแบบไฟล์ที่สร้างใหม่คือ `ยอดเงินบาท_ชื่อเรื่องจริง_ฉบับN.docx` เช่น `1,366.00บาท_รายงานขอซื้อวัสดุสำนักงาน_ฉบับ2.docx` PDF ของฉบับเดียวกันใช้ชื่อเดียวกันและเปลี่ยนนามสกุล

ชื่อ ZIP/PDF รวมขึ้นต้นด้วยยอดเงิน ตามด้วยชื่อชุดและชื่องาน โฟลเดอร์ใน ZIP ใช้ลำดับและชื่อเอกสารจริง รหัส D01–D14 ยังคงอยู่ใน metadata/สารบัญเพื่อให้ตรวจตามกระบวนงานได้ ชื่อไฟล์นำเข้าจากร้านค้าและเอกสารลงนามที่ตรึงแล้วไม่ถูกเปลี่ยนเอง

กรองอักขระที่ Windows ไม่รองรับ จำกัดความยาว และส่งชื่อภาษาไทยผ่าน `filename*` ชื่อไฟล์มีเลขฉบับให้แยกการสร้างซ้ำ ภายในฐานข้อมูลยังใช้ UUID แยกไฟล์ของแต่ละงาน

## โหมดประหยัดทรัพยากร

ที่ตัวอย่างเอกสาร ปิดช่อง “อัตโนมัติ” เพื่อจัดหน้าเฉพาะเมื่อกดปุ่มอัปเดตตัวอย่าง ระบบจดจำตัวเลือกในเบราว์เซอร์ เมื่อข้อมูลเปลี่ยนจะบอกว่าภาพยังไม่ตรงกับข้อมูลล่าสุด และปิดปุ่มพิมพ์ตัวอย่างเก่าจนกว่าจะอัปเดต

โหมดนี้ลดจำนวนครั้งที่เปิด Word ระหว่างกรอกข้อมูล ยังใช้การจัดหน้า ฟอนต์ ตรวจช่องบังคับ ยอดเงิน และเงื่อนไขก่อนส่งคลังชุดเดิม ไม่มีการลดความละเอียดไฟล์ส่งออกหรือใช้ภาพแทนข้อความ Word

ตัวดู PDF เดิมโหลดไลบรารีเมื่อใช้และวาดหน้าที่เลื่อนมาใกล้จออยู่แล้ว การลดภาระรอบนี้จึงเน้นการสั่งจัดหน้าระหว่างพิมพ์ ยังไม่ใช่โปรแกรมใหม่ที่ตัดความสามารถออก

## การตรวจ

- `scripts/test-procurement-correspondence.mjs` ใช้ฐานข้อมูลจำลองที่มี marker แยกจากข้อมูลจริง ทดสอบส่วนราชการสั้น ชื่อสั้น ชื่อยาว และตำแหน่งหลายบรรทัด
- `scripts/check-procurement-correspondence.py` ตรวจปลายเส้น ระยะกึ่งกลาง และข้อความที่ออกนอก A4 พร้อมตรวจภาพหลังจัดหน้าจริง
- `scripts/test-procurement-light-preview.mjs` ตรวจว่าโหมดประหยัดไม่เรียกจัดหน้าขณะพิมพ์ กดอัปเดตได้ กลับเป็นอัตโนมัติได้ และปิดการพิมพ์ภาพที่เก่าแล้ว
- ชุดทดสอบกระบวนงานเดิมตรวจการแก้ไขเฉพาะฉบับ การสร้างทั้งชุด หลักฐานส่งคลัง ประวัติและการกู้คืนควบคู่กัน
