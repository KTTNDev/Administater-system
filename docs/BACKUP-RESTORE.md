# สำรองและกู้คืนข้อมูล

ปุ่มส่งออกสำรองข้อมูลในหน้าตั้งค่าใช้ชุดสำรองรุ่น 2: ฐานข้อมูล `sarabun.sqlite`, JSON, ไฟล์แนบ PDF/ต้นฉบับ, ไฟล์ระเบียบโอนงบที่มีอยู่ และ manifest พร้อม SHA-256

ฐานข้อมูลชุดสำรองเก็บตารางธุรกิจ รวมไฟล์แนบ BLOB และสำเนากู้คืน ไม่รวมตาราง settings, รหัสผ่าน หรือ Google OAuth จึงต้องตั้งค่าหน่วยงาน/พื้นที่เก็บและเชื่อม Google ใหม่หลังย้ายระบบ ไฟล์ PDF ส่งออกสามารถสร้างใหม่จากร่างได้ ชุดสำรองต้องเก็บในพื้นที่ที่จำกัดสิทธิ์เช่นเดียวกับต้นฉบับ

## กู้คืนจากหน้าเว็บ

เปิดหน้าตั้งค่า → พื้นที่จัดเก็บและสำรองข้อมูล → โหลดรายการชุดสำรอง → ตรวจและกู้สำเนา
ตรวจจำนวนรายการแล้วพิมพ์คำยืนยันตามหน้าจอ ระบบตรวจ hash / SQLite integrity และสร้าง
ชุดสำรองข้อมูลปัจจุบันก่อนแทนข้อมูลธุรกิจในฐานที่ใช้งานอยู่ การตั้งค่าของเครื่องเดิมยังอยู่
ถ้ามีคนแก้ข้อมูลระหว่างตรวจและยืนยัน ระบบจะให้ตรวจชุดกู้คืนใหม่ก่อน

ชุดสำรองรวมงานประจำ โครงการ หลักฐานโครงการ และสายเอกสารหลัก–ลูกของคลังกฎหมายด้วย
การกู้ทั้งชุดย้อนทะเบียนเลขตามเวลาสำรอง ให้ตรวจเลขที่ออกหลังเวลานั้นก่อนใช้งานต่อ

## กู้ไปโฟลเดอร์แยกด้วยคำสั่ง (สำหรับผู้ดูแล)

ใช้ Node.js 22.13 ขึ้นไป จากโฟลเดอร์โปรเจกต์:

```powershell
node scripts/restore-backup.mjs "D:\backup\ชุดสำรองที่เลือก" "D:\sarabun-restored-check"
```

ปลายทางต้องเป็นพาธเต็มและยังไม่มีอยู่ โปรแกรมตรวจ hash ทุกไฟล์และ SQLite integrity ก่อนสร้างปลายทาง ไม่เขียนทับฐานข้อมูลที่ระบบใช้อยู่ และไม่รับชุดสำรองเก่ารุ่น 1

ผลลัพธ์: `data/sarabun.sqlite` และ `data/budget-references` พร้อมคำแนะนำใน RESTORE-README.txt
คำสั่งนี้ใช้กู้ไปตรวจในโฟลเดอร์แยกและไม่แทนฐานข้อมูลที่กำลังใช้ หากต้องการแทนข้อมูล
จากในโปรแกรม ให้ใช้ขั้นตอนกู้คืนจากหน้าเว็บด้านบน

SHA-256 ใช้ตรวจไฟล์เสียหาย ไม่ใช่ลายเซ็นยืนยันผู้สร้างชุดสำรอง จึงใช้ชุดสำรองจากแหล่งที่เชื่อถือได้เท่านั้น
