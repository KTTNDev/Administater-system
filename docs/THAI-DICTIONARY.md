# คลังคำภาษาไทย

เปิด **ตั้งค่า → คลังคำภาษาไทย** เพื่อเพิ่ม แก้ไข ลบ และค้นหาคำเฉพาะของหน่วยงาน คำเหล่านี้รวมอยู่ในชุดสำรอง/กู้คืน ไม่ต้องนำเข้าใหม่เมื่อย้ายเครื่อง

## ตรวจคำในหนังสือ

กด **ตรวจคำไทย** ใต้ช่องเนื้อหา ระบบตรวจในเครื่องโดยใช้รายการคำ PyThaiNLP 62,106 คำ และคำเฉพาะของหน่วยงาน คำที่ไม่พบเป็นเพียงคำที่ควรตรวจ อาจเป็นชื่อบุคคล ชื่อหน่วยงาน หรือศัพท์ใหม่ ไม่ใช่ข้อยืนยันว่าผิด

คำผิดที่ระบบมีคำแนะนำจะแสดงปุ่มให้เลือกแก้ทีละตำแหน่ง ผู้ใช้ตัดสินใจก่อนเสมอ หากแก้ข้อความระหว่างตรวจ ต้องตรวจใหม่เพื่อป้องกันการแทนผิดตำแหน่ง ระบบยังไม่ตรวจไวยากรณ์หรือความหมายทั้งประโยค

## ไม่แยกคำหรือคำคู่

เลือกข้อความสั้น ๆ ในช่องเนื้อหา แล้วกด **ไม่แยกคำที่เลือก** หรือเพิ่มคำในตั้งค่าและเลือก **ให้คำนี้อยู่บรรทัดเดียวกัน** เช่น ชื่อครุภัณฑ์หรือคำคู่ที่ใช้บ่อย

- หน้าตัวอย่างและ PDF จัดข้อความกลุ่มนี้อยู่ด้วยกัน รวมถึงคำที่มีตัวหนาบางส่วน
- หากเหลือที่ไม่พอ กลุ่มคำย้ายไปบรรทัดถัดไปทั้งกลุ่ม
- ใช้คำหรือวลีสั้น ๆ เท่านั้น คำที่ยาวเกินช่องตารางหรือหน้ากระดาษจะแจ้งให้ปรับก่อนส่งออก
- ไม่เพิ่มการขึ้นบรรทัดกลางย่อหน้าในข้อความต้นฉบับ
- Word ยังคงเป็นข้อความและตารางที่แก้ต่อได้ ใช้ Thai Distributed และตัวเชื่อมคำที่มองไม่เห็น (U+2060) ภายในกลุ่มคำ การคัดลอกจาก Word จึงอาจมีอักขระนี้ติดมาด้วย
- Word ใช้ตัวจัดหน้าของตัวเอง ระยะบรรทัดอาจแตกต่างตามรุ่นโปรแกรม ควรตรวจหน้าก่อนพิมพ์ โดยเฉพาะหลังแก้ใน Word
- คลังคำนี้ทำงานในระบบสารบรรณ ไม่ใช่การติดตั้งพจนานุกรมเข้า Microsoft Word
